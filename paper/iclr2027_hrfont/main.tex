\begin{abstract}
We introduce \method, a framework for extending a font family to new scripts from a few Chinese reference glyphs.
The central challenge is to translate a family's visual language into characters whose structures differ from those observed.
\method addresses this challenge through two complementary forms of conditioning.
Mean-Delta expresses same-character examples from a font bank as a multi-scale variation prior relative to neutral content.
Target-character appearance completion learns how reference appearance should be expressed in the requested glyph, using target-glyph appearance descriptors as training supervision.
The resulting conditions guide a diffusion generator toward recognizable characters with a coherent family identity.
We also formulate a cross-script completion benchmark that evaluates character identity, reference consistency, and family compatibility, with script-aware data curation and controlled reference budgets.

\section{Introduction}
A designer extending a Chinese typeface to Latin or kana needs more than a recognizable outline.
The new glyphs should belong to the same family: weight, contrast, terminals, and decorative treatment should feel coherent across scripts.
A few Chinese examples provide evidence of that visual language, but they leave its realization in the target characters open.
The design of a Latin \emph{g}, for example, requires choices that are not directly visible in a Chinese reference glyph.
Cross-script font completion therefore calls for both a vocabulary of target-character variations and a model of how the observed appearance applies to each character.

Few-shot generators learn to synthesize glyphs from content and reference images.
FontDiffuser uses conditional diffusion and multi-scale content aggregation~\citep{yang2023fontdiffuser};
FSFont learns fine-grained correspondence between content and reference features~\citep{tang2022fsfont}.
Font-bank methods such as CF-Font enrich content representations using corresponding glyphs from basis fonts~\citep{wang2023cffont}.
These approaches provide useful ingredients for completion.
The cross-script setting makes a further distinction important: available glyph variations describe possible designs, whereas the reference images specify the family to which the result should belong.

We develop \method around this distinction.
The first component, \emph{Mean-Delta}, represents a requested character through anchor-relative feature changes supported by a font bank.
The neutral rendering supplies identity, and the residual supplies an adaptable variation prior.
The second component, \emph{\tc} (TC), predicts an appearance descriptor for the requested character from its neutral content and the observed references.
Training glyphs provide direct supervision for this prediction.
Together, these components connect \emph{how the character can vary} with \emph{how the family's appearance should be realized}.

This formulation also shapes the evaluation.
Matching a held-out target image is useful, but a plausible completion can differ from that particular design.
We therefore assess three outcomes: whether the glyph has the requested identity, whether it expresses the references' visible attributes, and whether it fits the target family across scripts.
Script-aware curation establishes which font--character pairs provide meaningful supervision, while fixed reference episodes make comparisons reproducible.

\Needspace{11\baselineskip}
Our contributions are:
\begin{itemize}
\item A cross-script font completion formulation and evaluation protocol that distinguish character identity, reference consistency, and family compatibility.
\item Mean-Delta, an anchor-relative, multi-scale glyph variation prior that connects a neutral content representation to corresponding examples in a training font bank.
\item Target-character appearance completion, a supervised predictor that translates reference appearance into a target-conditioned descriptor for diffusion synthesis.
\end{itemize}

\section{Related Work}
\paragraph{Cross-script and few-shot font generation.}
FTransGAN studies few-shot transfer between languages with multi-level attention~\citep{li2021ftransgan}.
FontDiffuser generates glyphs by conditional denoising and uses multi-scale content aggregation and style contrastive learning~\citep{yang2023fontdiffuser}.
FSFont uses content queries to aggregate fine-grained local reference styles~\citep{tang2022fsfont}.
\method builds on conditional generation and local reference evidence, and introduces a supervised intermediate prediction: the appearance of the requested target glyph.
This prediction connects reference observations to the target character before the generator renders the image.

\paragraph{Font-bank content representations.}
CF-Font projects content features into a space spanned by corresponding glyphs from basis fonts~\citep{wang2023cffont}.
Mean-Delta shares the use of same-character bank evidence.
Its interface expresses that evidence as a residual from a fixed neutral anchor and consumes the residual through the structural conditioning path, alongside separately supplied neutral content.
The shared anchor keeps the content input stable while the residual conditions its adaptation.
Our evaluation tests this interface under shared bank access and training budgets.

\paragraph{Appearance transfer and completion.}
Feature moments provide a compact appearance representation in neural style transfer; AdaIN aligns content-feature statistics with those of a style image~\citep{huang2017adain}.
Reference attention retrieves useful features from observed glyphs.
TC adds a predictive objective: estimate how those observations are expressed by a different character.
The target-content query and target-glyph supervision give this objective a concrete meaning.
Multi-scale feature statistics provide the appearance representation, and the generator receives the prediction as an additive update to its global reference tokens.
Local reference features remain available for spatially detailed synthesis.

\section{Cross-Script Font Completion}
\label{sec:task}
Let $c$ be a requested target character and $x_c^0$ its rendering in a neutral font.
For a target family $f$, the observed reference set is
$\Rset_f=\{(a_i,r_i)\}_{i=1}^{n}$, where $a_i$ is a Chinese character and $r_i$ its rendering in $f$.
The task is to generate $\hat y_{f,c}$ with the identity of $c$ and an appearance compatible with $f$.
The evaluation font is held out from training.
A bank $\Bset$ contains training-font renderings of the reference and target characters.
During training, an episode excludes its own font from donor retrieval.

\paragraph{Three evaluation dimensions.}
\emph{Identity} measures whether the output represents the requested character.
\emph{Reference consistency} measures agreement with visible attributes such as weight, contrast, stroke endings, and texture.
\emph{Family compatibility} measures whether the generated glyph is a coherent extension of the family across scripts.
The latter includes character-specific decisions whose exact realization is not shown in the reference set.
Paired target-image measurements complement these dimensions with reconstruction diagnostics.

\paragraph{Script-aware supervision.}
A font file can contain several scripts with different design conventions, fallback glyphs, or inconsistent coverage.
We curate valid font--character pairs and eligible donors by script, preserving the font-level train/validation/test split.
A mismatch in design conventions calls for family-level inspection; automatic similarity alone does not determine validity.
The released protocol records pair validity, donor eligibility, and the reference episode used for each output.

\section{Method}
\label{sec:method}
\subsection{Overview}
We use a conditional diffusion generator with frozen content and style encoders, $E_c$ and $E_s$.
The content encoder supplies multi-scale features of the neutral target.
The style encoder supplies global reference tokens and, for the local-reference configuration, local reference features.
Mean-Delta conditions the structural interaction path.
TC updates the global reference tokens with predicted target-character appearance.
The denoiser thus receives
\begin{equation}
 \hat\epsilon=\epsilon_\theta\bigl(x_t,t,E_c(x_c^0),\Delta_c(\Rset_f),
                       G'(\Rset_f,c),L(\Rset_f)\bigr).
 \label{eq:denoiser}
\end{equation}
Here $x_t$ is the noisy target image, $G'$ denotes the appearance-completed global tokens, and $L$ denotes local reference tokens when present.
We evaluate both global and global-plus-local configurations using the same TC definition.

\subsection{Mean-Delta: a glyph variation prior}
The bank supplies examples of how the requested character is realized in different fonts.
To prioritize a relevant neighborhood, we compare the target references with bank renderings of the same reference characters:
\begin{align}
 s_j(\Rset_f) &= \frac{1}{n}\sum_{i=1}^{n}
    \cos\!\left(\bar E_s(r_i),\bar E_s(B_{j,a_i})\right),\\
 \alpha_j &= \frac{\exp(s_j/\tau)}
                  {\sum_{\ell\in\mathcal J_c(\Rset_f)}\exp(s_\ell/\tau)},
       \qquad j\in\mathcal J_c(\Rset_f).
 \label{eq:retrieval}
\end{align}
$\bar E_s$ is a pooled descriptor.
$\mathcal J_c$ contains the top-$K$ eligible training fonts after removing the episode font and script-invalid donors.
The implementation uses $K=10$ and $\tau=0.07$.

For each content scale $s$, Mean-Delta is
\begin{equation}
 \Delta_c^s=\sum_{j\in\mathcal J_c}\alpha_j
       \left[E_c^s(B_{j,c})-E_c^s(x_c^0)\right].
 \label{eq:delta}
\end{equation}
Every donor renders the same requested character.
Subtracting a common anchor expresses the bank evidence in coordinates relative to the content already available to the generator.
The resulting multi-scale tensors feed the deformable structural interaction modules.

Retrieval defines a reference-conditioned prior over available variations.
Similarity in the observed script is a useful ranking signal; the generator learns how the resulting prior applies to the target script.
The donor residual is therefore an adaptable condition rather than a prescribed target design.
Uniform-weight and absolute-feature controls test the contribution of neighborhood weighting and the anchor-relative interface.

\subsection{Target-character appearance completion}
\label{sec:tc}
TC learns the appearance of a target character from reference observations.
Its input pairs a descriptor of each reference with a query describing the requested content.
Its teacher is the appearance descriptor of the corresponding training target.

\paragraph{Appearance representation.}
Let $\phi_\ell(x)$ denote three frozen VGG16~\citep{Simonyan15} feature maps with channel counts $64$, $128$, and $256$.
We summarize each map by its spatial channel means and population standard deviations:
\begin{equation}
 \psi(x)=\mathop{\mathrm{concat}}_{\ell=1}^{3}
       \left[\mu_{HW}(\phi_\ell(x)),\sigma_{HW}(\phi_\ell(x))\right]
       \in\mathbb R^{896}.
\end{equation}
Training-target statistics define a per-dimension standardization $S$ shared by reference descriptors and target teachers.
The descriptors summarize multi-scale activation strength and variability.
They give TC a compact appearance target while the diffusion generator handles the spatial arrangement of strokes.

\paragraph{Content-conditioned prediction.}
The five pooled content scales form $u_c\in\mathbb R^{707}$.
Linear projections map $u_c$ and the standardized reference descriptors into a 256-dimensional attention space:
\begin{align}
 q_c &= W_q u_c,\qquad v_i=W_r S(\psi(r_i)),\\
 h_c &= \operatorname{LN}\!\left(q_c+
          \operatorname{MHA}(q_c,\{v_i\},\{v_i\})\right),\\
 \hat a_{f,c} &= \operatorname{MLP}([h_c;q_c])\in\mathbb R^{896}.
 \label{eq:tc}
\end{align}
The attention uses eight heads and masks padded references.
The content query also enters the prediction MLP directly, allowing character-dependent predictions even for a single reference.
The same family can consequently yield different descriptors for different requested characters.

\paragraph{Supervision and injection.}
For training target $y_{f,c}$, the teacher is $a^*_{f,c}=S(\psi(y_{f,c}))$.
TC minimizes
\begin{equation}
 \mathcal L_{\mathrm{comp}}=
   \operatorname{SmoothL1}\!\left(\hat a_{f,c},
                                \operatorname{stopgrad}(a^*_{f,c})\right).
 \label{eq:completion}
\end{equation}
A learned projection $W_o:\mathbb R^{896}\rightarrow\mathbb R^{1024}$ converts the prediction into a shared residual for the existing nine global tokens:
\begin{equation}
 G'_j=G_j+W_o\hat a_{f,c},\qquad j=1,\ldots,9.
 \label{eq:injection}
\end{equation}
$W_o$ includes a bias; its weights and bias start at zero.
This initialization begins joint optimization from the parent generator.
The global tokens retain their existing spatial information, and local reference tokens supply additional detail.
TC is trained on reference descriptors and neutral content, so it learns a target-appearance mapping complementary to the bank-derived variation condition.

\subsection{Training and generation}
Training first fits the appearance predictor using cached descriptors.
Joint training then optimizes the predictor, its output projection, and the denoiser:
\begin{equation}
 \mathcal L=\mathcal L_{\mathrm{diff}}
       +0.01\mathcal L_{\mathrm{perc}}
       +0.5\mathcal L_{\mathrm{off}}
       +0.01\mathcal L_{\mathrm{comp}}.
\end{equation}
$\mathcal L_{\mathrm{diff}}$ is the epsilon-prediction mean squared error;
the perceptual and offset terms follow the inherited generation backbone.
The content, style, and VGG encoders stay frozen.
Each training episode uses one to eight Chinese references and a valid target glyph from the same font.

The TC teacher is used only for its supervised loss.
The denoiser always receives the predicted descriptor, including during training.
Classifier-free condition dropout masks the TC residual together with the reference condition, while the completion loss uses the original observed inputs.
The structural condition follows the shared source-drop policy.
At inference, TC is evaluated once for each content--reference pair and reused across denoising steps.

\section{Experiments}
\label{sec:experiments}
\subsection{Data and settings}
The corpus contains 260 fonts partitioned into 228 training, 16 validation, and 16 test fonts.
The inventory comprises 295 target characters and 338 Chinese reference characters.
Protocol A renders RGB glyphs at $96\times96$, with a shared font size within each font and neutral Noto Sans CJK Regular content.
The current clean training mapping retains 56,429 target pairs.
The stratified evaluation panel spans 47 characters covering Latin, diacritics, kana, and phonetic symbols; validity filtering retains 704 test pairs.

Reference-budget evaluation uses nested sets of 1, 2, 4, and 8 characters.
All methods in a comparison receive the same ordered reference set, and Mean-Delta retrieval uses that episode's references.
The main reference manifest and checkpoint selection are finalized on validation data.
The appendix records reference characters, bank eligibility, sampler, and provenance.

\paragraph{Training settings.}
The current joint experiments use eight V100 GPUs, eight samples per device, FP16 arithmetic, and gradient clipping at 1.0.
The denoiser learning rate is $10^{-5}$; new TC parameters use $10^{-4}$.
Short joint stages run for 5,000 updates with 200 warmup updates and checkpoints at 2,500 and 5,000.
TC pretraining uses batch size 256, learning rate $3\times10^{-4}$, and up to 2,000 updates.
Matched continuation controls start from the same parent weights with the same training schedule.
Complete resolved settings appear in Appendix~\ref{app:repro}.

\subsection{Comparisons and measurements}
External comparisons cover conditional diffusion (FontDiffuser), cross-language transfer (FTransGAN), font-bank content fusion (CF-Font), and fine-grained reference attention (FSFont).
Each method is accompanied by its reference budget, bank access, pretraining data, and cross-script adaptation.
Internal comparisons hold the content/style encoders and reference interface fixed while changing the structural source or TC.
The strongest validation baseline is retained in the main comparison.

We report character recognition accuracy, blind paired style preference, and family compatibility.
Human comparison displays the neutral target and the same reference set with randomized method positions and an explicit tie option.
The learned compatibility evaluator is trained and calibrated separately from the generator; its definition, calibration, and agreement with human judgments are reported with the final results.
L1, SSIM, and LPIPS provide paired reconstruction diagnostics.
Results are aggregated by font and script over the same valid examples.

\subsection{Contribution studies}
\paragraph{Glyph variation prior.}
Matched structural-source experiments compare the reference-derived structural input with Mean-Delta while preserving the reference interface.
A same-bank absolute-feature control tests anchor-relative conditioning.
A uniform-weight control measures the contribution of reference-based donor ranking.
Each comparison uses the same training budget and reports identity and appearance jointly.

\paragraph{Target-character appearance completion.}
We compare TC with ordinary continuation from each of the G2 and G2-RL parents.
These pairs test the incremental value of appearance completion on global and global-plus-local reference interfaces.
We also evaluate a reference-only predictor with a constant content query and a same-capacity branch trained without target-descriptor supervision.
The reference-only predictor tests character conditioning.
The latter control measures the value of the complete supervised initialization and training recipe.

\paragraph{Complementarity.}
A factorial experiment varies Mean-Delta and TC under a fixed reference interface.
The comparison tests their separate and combined effects on family compatibility and reference consistency.
The initialization and structural-source treatment are shared within this study.
This is a training comparison; inference-time condition removal is reported separately as sensitivity analysis.

\section{Discussion}
The two conditions provide different forms of information.
Mean-Delta brings target-character examples into the generator's content coordinates.
TC learns a target-specific appearance prediction from observed references.
Their combination gives the generator a structural prior and a supervised appearance destination.
The contribution studies measure how these roles translate into image quality.

The current representation operates on $96\times96$ raster glyphs.
Spatial feature statistics summarize appearance compactly but do not specify the location of every ornament or terminal.
Fine decorative placement remains a synthesis problem for the denoiser and its local reference interface.
Bank coverage also determines the available examples for rare target designs.
Extending the formulation to higher-resolution glyphs and complete typographic layout is a natural next step.

\section{Conclusion}
\method frames cross-script font generation as coherent family completion.
Mean-Delta provides a bank-supported variation prior relative to neutral content, and target-character appearance completion predicts how reference observations apply to the requested glyph.
The accompanying evaluation separates identity, reference consistency, and family compatibility.
Together, the formulation and two conditioning components establish a practical framework for extending a font's visual language across scripts.

\paragraph{Implementation details.}
VGG descriptors use ImageNet normalization and FP32 statistics.
Only clean training targets fit descriptor standardization.
The predictor is pretrained for at most 2,000 updates with 100 warmup updates.
Joint stages load parent weights and create a new optimizer and scheduler.
The local-reference learning rate is preserved within each matched pair.
The default joint configuration uses the denoiser rate for existing local projections.
The separate local-reference pilot uses $10^{-4}$ for its new local projection.

\paragraph{Randomness and uncertainty.}
Training uses random state 3407.
Evaluation pairs reference episodes and diffusion noise across methods.
Planned 95\% intervals resample fonts while keeping paired method outputs together.
These intervals describe variation across evaluated fonts.

\paragraph{Reference episodes and sampler.}
The primary nested episode is specified by Unicode code points:
U+5C71, U+6C34, U+4E91, U+6708, U+91D1, U+77F3, U+5FC3, U+6587.
The 1/2/4/8-shot sets use prefixes of this list.
Earlier exploratory boards used a different reference episode and retain separate provenance.
The intended common inference protocol is DPM-Solver++ order 2, 20 steps, and guidance scale 7.5.
The TC sampling path is validated against the common protocol before final paired reporting.

\paragraph{Model selection.}
Validation panels guide model and checkpoint selection using appearance, readability, and identity.
The final selection uses the full clean validation split.
Exploratory test visualizations are retained with their dates; subsequent selection uses validation data.
All reported methods are scored over an explicitly intersected valid sample set.
