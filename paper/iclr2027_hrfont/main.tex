\begin{abstract}
We introduce \method, a framework for extending a font family to new scripts from a few Chinese reference glyphs.
The central challenge is to translate a family's visual language into characters whose structures differ from those observed.
\method addresses this challenge through two complementary forms of conditioning.
Dynamic Delta expresses same-character examples from a font bank as anchor-relative structural variations and learns to combine them as generation unfolds.
Target-character appearance completion reads multi-scale local reference features to predict a spatial appearance representation of the requested glyph, supervised by training-target features.
The resulting conditions guide a diffusion generator toward recognizable characters with a coherent family identity.
We also formulate a cross-script completion benchmark that evaluates character identity, reference consistency, and family compatibility, with script-aware data curation and controlled reference budgets.

\section{Introduction}
A designer extending a Chinese typeface to Latin or kana needs more than a recognizable outline.
The new glyphs should belong to the same family: weight, contrast, terminals, and decorative treatment should feel coherent across scripts.
A few Chinese examples provide evidence of that visual language, but they leave its realization in the target characters open.
The design of a Latin \emph{g}, for example, requires choices that are not directly visible in a Chinese reference glyph.
Cross-script font completion therefore calls for both a vocabulary of target-character variations and a model of how the observed appearance applies to each character.

Few-shot generators learn to synthesize glyphs from content and reference images.
FontDiffuser uses conditional diffusion and multi-scale content aggregation~\citep{yang2023fontdiffuser};
FSFont learns fine-grained correspondence between content and reference features~\citep{tang2022fsfont}.
Font-bank methods such as CF-Font enrich content representations using corresponding glyphs from basis fonts~\citep{wang2023cffont}.
These approaches provide useful ingredients for completion.
The cross-script setting makes a further distinction important: available glyph variations describe possible designs, whereas the reference images specify the family to which the result should belong.

We develop \method around this distinction.
The first component, \emph{Dynamic Delta}, represents a requested character through anchor-relative feature changes supported by a font bank.
The neutral rendering supplies identity, while a learned router combines the available variations at each spatial location and denoising step.
The second component, \emph{\tc} (TC), predicts a spatial appearance representation for the requested character from its neutral content and the observed references.
Its online reference reader preserves local evidence before organizing that evidence around the target character.
Training glyphs provide direct supervision for this prediction.
Together, these components connect \emph{how the character can vary} with \emph{how the family's appearance should be realized}.
Figure~\ref{fig:overview} summarizes the model.

This formulation also shapes the evaluation.
Matching a held-out target image is useful, but a plausible completion can differ from that particular design.
We therefore assess three outcomes: whether the glyph has the requested identity, whether it expresses the references' visible attributes, and whether it fits the target family across scripts.
Script-aware curation establishes which font--character pairs provide meaningful supervision, while fixed reference episodes make comparisons reproducible.

\Needspace{11\baselineskip}
Our contributions are:
\begin{itemize}
\item A cross-script font completion formulation and evaluation protocol that distinguish character identity, reference consistency, and family compatibility.
\item Dynamic Delta, an anchor-relative glyph variation space with spatially and temporally adaptive combination of corresponding training-bank examples.
\item Target-character appearance completion, an online local-reference reader that learns a target-aligned appearance memory through direct feature supervision.
\end{itemize}

\section{Related Work}
\paragraph{Cross-script and few-shot font generation.}
FTransGAN studies few-shot transfer between languages with multi-level attention~\citep{li2021ftransgan}.
FontDiffuser generates glyphs by conditional denoising and uses multi-scale content aggregation and style contrastive learning~\citep{yang2023fontdiffuser}.
FSFont uses content queries to aggregate fine-grained local reference styles~\citep{tang2022fsfont}.
\method builds on conditional generation and local reference evidence, and introduces a supervised intermediate prediction: the appearance of the requested target glyph.
This prediction connects reference observations to the target character before the generator renders the image.

\paragraph{Font-bank content representations.}
CF-Font projects content features into a space spanned by corresponding glyphs from basis fonts~\citep{wang2023cffont}.
Dynamic Delta shares the use of same-character bank evidence.
Its interface expresses that evidence as a residual from a fixed neutral anchor and consumes the residual through the structural conditioning path, alongside separately supplied neutral content.
The shared anchor keeps the content input stable while a denoising-conditioned router adapts the mixture of residuals.
Our evaluation tests this interface under shared bank access and training budgets.

\paragraph{Appearance transfer and completion.}
Feature statistics provide appearance representations in neural style transfer~\citep{huang2017adain}, while local attention retrieves features from observed glyphs~\citep{tang2022fsfont}.
TC organizes such observations into a target-aligned spatial memory.
Its distinctive learning objective predicts the feature map of a different character in the same family.
This supervision shapes both reference extraction and target-conditioned aggregation, and the resulting memory enters the generator through an additional reference-attention readout.

\section{Cross-Script Font Completion}
\label{sec:task}
Let $c$ be a requested target character and $x_c^0$ its rendering in a neutral font.
For a target family $f$, the observed reference set is
$\Rset_f=\{(a_i,r_i)\}_{i=1}^{n}$, where $a_i$ is a Chinese character and $r_i$ its rendering in $f$.
The task is to generate $\hat y_{f,c}$ with the identity of $c$ and an appearance compatible with $f$.
The evaluation font is held out from training.
A bank $\Bset$ contains training-font renderings of the reference and target characters.
During training, an episode excludes its own font from donor retrieval.

\paragraph{Three evaluation dimensions.}
\emph{Identity} measures whether the output represents the requested character.
\emph{Reference consistency} measures agreement with visible attributes such as weight, contrast, stroke endings, and texture.
\emph{Family compatibility} measures whether the generated glyph is a coherent extension of the family across scripts.
The latter includes character-specific decisions whose exact realization is not shown in the reference set.
Paired target-image measurements complement these dimensions with reconstruction diagnostics.

\paragraph{Script-aware supervision.}
A font file can contain several scripts with different design conventions, fallback glyphs, or inconsistent coverage.
We curate valid font--character pairs and eligible donors by script, preserving the font-level train/validation/test split.
A mismatch in design conventions calls for family-level inspection; automatic similarity alone does not determine validity.
The released protocol records pair validity, donor eligibility, and the reference episode used for each output.

\section{Method}
\label{sec:method}
\subsection{Overview}
We use a conditional diffusion generator with a frozen content encoder $E_c$ and a frozen style encoder $E_s$.
The content encoder supplies multi-scale features of the neutral target.
The style encoder supplies the global reference tokens, the pooled descriptors that drive donor retrieval, and the two intermediate maps read by the second structural branch.
A separate trainable local encoder $E_{\mathrm{loc}}$, initialized from the first three blocks of $E_s$, reads the reference pixels online.
Dynamic Delta conditions structural interaction from two donor-side residuals, while TC turns local evidence into target-aligned appearance tokens.
The denoiser receives
\begin{equation}
 \hat\epsilon=\epsilon_\theta\bigl(x_t,t,E_c(x_c^0),\Delta^{\mathrm{ec}}_{c,t}(\Rset_f),\Delta^{\mathrm{es}}_{c,t}(\Rset_f),
                       G(\Rset_f),A(\Rset_f,c)\bigr).
 \label{eq:denoiser}
\end{equation}
Here $x_t$ is the noisy target image, $G$ contains nine global reference tokens, and $A$ contains 144 appearance tokens arranged around the target's $12\times12$ content grid.

\subsection{Dynamic Delta: a structural variation space}
The bank supplies examples of how the requested character is realized in different fonts.
To prioritize a relevant neighborhood, we compare the target references with bank renderings of the same reference characters:
\begin{align}
 s_j(\Rset_f) &= \frac{1}{n}\sum_{i=1}^{n}
    \cos\!\left(\bar E_s(r_i),\bar E_s(B_{j,a_i})\right),\\
 \alpha_j &= \frac{\exp(s_j/\tau)}
                  {\sum_{\ell\in\mathcal J_c(\Rset_f)}\exp(s_\ell/\tau)},
       \qquad j\in\mathcal J_c(\Rset_f).
 \label{eq:retrieval}
\end{align}
$\bar E_s$ is a pooled descriptor.
$\mathcal J_c$ contains the top-$K$ eligible training fonts after removing the episode font, its explicit weight variants, and script-invalid donors; the removal precedes the normalization of $\alpha$.

The structural condition is formed at two of the content scales, $48\times48$ and $24\times24$.
At each of them we retain a set of anchor-relative candidates:
\begin{equation}
 d^{\mathrm{ec}}_{j,c}=E_c^{\rho}(B_{j,c})-E_c^{\rho}(x_c^0),\qquad j\in\mathcal J_c,
 \label{eq:delta}
\end{equation}
where $\rho$ is the content scale read by the module that consumes the candidates.
Every donor renders the same requested character.
Subtracting a common anchor expresses the bank evidence in coordinates relative to the content already available to the generator.
These candidates define a bank-supported space of possible changes to the neutral structure.

The same donors are also read in the coordinates of the style encoder.
For donor $f_j$ and requested character $c$, we take the first two intermediate maps of the frozen style encoder, at the same two scales, and form
\begin{equation}
 d^{\mathrm{es}}_{j,c}=E_s^{\rho}(x_{f_j,c})-E_s^{\rho}(x_c^0),
 \label{eq:style_delta}
\end{equation}
where $x_{f_j,c}$ is the donor's rendering of the requested character and $x_c^0$ is the neutral rendering.
A bias-free $1\times1$ adapter maps the difference to the branch width and is initialized as the identity.
Both branches read the same neighborhood $\mathcal J_c$ and the same prior $\alpha$.

Retrieval supplies an initial distribution $\alpha$, and a learned router adapts that distribution to the current synthesis state.
Each branch routes and predicts its own offsets.
At location $p$ of structural module $\ell$, at scale $\rho$, the router computes
\begin{align}
 q^{b}_{\ell,t,p} &= Q^{b}_\ell(h_{\ell,t})_p+C^{b}_\ell(E_c^{\rho}(x_c^0))_p
                 +R^{b}_\ell(\bar G)+T^{b}_\ell(t),\\
 w^{b}_{j,\ell,t,p} &= \operatorname{softmax}_{j}\!\left[
       \log\alpha_j+\gamma^{b}_\ell\cos(q^{b}_{\ell,t,p},\Pi^{b}_\ell(d^{b}_{j,c})_p)\right],\\
 \Delta^{b}_{\ell,t,p} &= \operatorname{Offset}^{b}_\ell\Bigl(h_{\ell,t},\;
       \textstyle\sum_{j\in\mathcal J_c}w^{b}_{j,\ell,t,p}\,d^{b}_{j,c,p}\Bigr),
       \qquad b\in\{\mathrm{ec},\mathrm{es}\},
 \label{eq:dynamic_delta}
\end{align}
where $d^{\mathrm{ec}}_{j,c}$ is the content-encoder difference of \eqref{eq:delta} and $d^{\mathrm{es}}_{j,c}$ the style-encoder difference of \eqref{eq:style_delta}.
$h_{\ell,t}$ is the generator's content-side hidden state, $\bar G$ is the mean global reference token, and $\gamma^{b}_\ell$ is learned.
The two offsets are combined through a learned per-layer scalar,
\begin{equation}
 \Delta_{\ell,t,p}=\Delta^{\mathrm{ec}}_{\ell,t,p}+\tanh(g_\ell)\,\Delta^{\mathrm{es}}_{\ell,t,p},
 \label{eq:gate}
\end{equation}
with $g_\ell$ initialized at zero.
The combined residual drives deformable structural interaction with the neutral content.

The weights are nonnegative and sum to one: adaptation selects within the available residual variations at each location.
Reference similarity narrows the search neighborhood; target content and the evolving denoising state determine how it is used.
This separates neighborhood retrieval from cross-script realization.
Mean-Delta is recovered by fixing $w_j=\alpha_j$.

\subsection{Target-character appearance completion}
\label{sec:tc}
TC learns how local reference observations should be expressed in the requested character.
It extracts evidence at multiple scales and arranges it into a target-conditioned memory that serves both appearance prediction and synthesis.

\paragraph{Online local evidence.}
For each reference, $E_{\mathrm{loc}}$ produces a $24\times24\times128$ feature map and a $12\times12\times256$ map.
A $1\times1$ projection maps the shallower features to 256 channels.
Flattening and concatenating both maps yields 720 tokens per reference.
All valid references form a joint evidence sequence $V_f\in\mathbb R^{720n\times256}$.
The encoder processes valid images only, and attention masks padded positions.
Observations stay separate until the target-conditioned readout.

\paragraph{Target-aligned memory.}
The neutral content grid $U_c\in\mathbb R^{144\times256}$, taken from the $12\times12$ scale of $E_c(x_c^0)$, defines one query per target location.
Learned positional slots $P$ accompany the content queries:
\begin{align}
 Q_c &= W_q U_c+P,\\
 H_{f,c} &= \operatorname{Attn}(Q_c,W_kV_f,W_vV_f),\\
 M_{f,c} &= H_{f,c}+\operatorname{MLP}(\operatorname{LN}(H_{f,c})),\\
 A_{f,c} &= W_o M_{f,c},\qquad \hat F_{f,c}=W_a M_{f,c}.
 \label{eq:tc}
\end{align}
Attention uses four heads, per-head query/key normalization, and FP32 softmax.
$A_{f,c}\in\mathbb R^{144\times1024}$ conditions synthesis, while $\hat F_{f,c}\in\mathbb R^{144\times128}$ is the supervised appearance readout.

\paragraph{Supervision and injection.}
For training target $y_{f,c}$, a frozen VGG16~\citep{Simonyan15} feature extractor supplies
$F^*_{f,c}=S(\operatorname{Pool}_{12\times12}(\phi_2(y_{f,c})))$.
The second feature map has 128 channels; $S$ uses per-channel statistics fitted on clean training targets.
Both $\hat F_{f,c}$ and $F^*_{f,c}$ keep the $12\times12$ grid.
TC minimizes
\begin{equation}
 \mathcal L_{\mathrm{comp}}=
   \operatorname{SmoothL1}\!\left(\hat F_{f,c},
                                \operatorname{stopgrad}(F^*_{f,c})\right).
 \label{eq:completion}
\end{equation}
At each up-path reference-attention layer, the generator reads the global tokens and the appearance memory separately:
\begin{equation}
 Z=\operatorname{CA}(h,G)+\eta\,r(u)\operatorname{CA}(h,A_{f,c}).
 \label{eq:injection}
\end{equation}
The two reads share attention projections.
The gain $\eta$ is initialized at $0.01$ and ramped over the first 1,000 updates.
$G$ carries the family-level reference summary, while the spatial memory supplies target-local evidence.
The readout and the synthesis tokens are both produced from $M_{f,c}$.

\subsection{Training and generation}
We jointly optimize the local reader, both Delta branches, and the denoiser from a pretrained generation checkpoint:
\begin{equation}
 \mathcal L=\mathcal L_{\mathrm{diff}}
      +0.01\mathcal L_{\mathrm{perc}}
      +r(u)\bigl(0.01\mathcal L_{\mathrm{comp}}+0.05\mathcal L_{\mathrm{detail}}\bigr).
 \label{eq:objective}
\end{equation}
$\mathcal L_{\mathrm{diff}}$ is the epsilon-prediction mean squared error.
The perceptual term averages three VGG feature losses.
$\mathcal L_{\mathrm{comp}}$ supervises the appearance readout of \eqref{eq:completion}, and $\mathcal L_{\mathrm{detail}}$ is a region-weighted endpoint term over the ink added and removed by the design; the mask definitions and the $\sqrt{\bar\alpha_t}$ weighting are listed in Appendix~\ref{app:repro}.
The content, style, and VGG encoders stay frozen; the local reference encoder and the routing modules of both branches are trainable.
Each training episode uses one to eight Chinese references and a valid target glyph from the same font.
Each update draws 64 targets under fixed script quotas, with an oversampling of fonts whose design departs from the neutral rendering; donor retrieval excludes the episode font and its explicit weight variants.
$r(u)$ ramps over the first 1,000 updates.

The TC teacher is used only for its supervised loss.
The denoiser always receives the predicted appearance memory, including during training.
Classifier-free condition dropout jointly removes the global reference, local appearance, neutral-content, and structural conditions from the denoiser, and the structural offsets are zeroed after the routing weights are normalized.
A source-drop event removes the structural condition by the same rule; the completion loss retains its observed inputs.
At inference, TC is evaluated once for each content--reference pair and reused across denoising steps, while Delta weights adapt at every structural module and step.

\section{Experiments}
\label{sec:experiments}
\subsection{Data and settings}
The corpus contains 260 fonts partitioned into 228 training, 16 validation, and 16 test fonts.
The inventory comprises 295 target characters and 338 Chinese reference characters.
Protocol A renders RGB glyphs at $96\times96$, with a shared font size within each font and neutral Noto Sans CJK Regular content.
The current clean training mapping retains 56,429 target pairs.
The stratified evaluation panel spans 47 characters covering Latin, diacritics, kana, and phonetic symbols; validity filtering retains 704 test pairs.

Reference-budget evaluation uses nested sets of 1, 2, 4, and 8 characters.
All methods in a comparison receive the same ordered reference set, and Delta retrieval uses that episode's references.
The main reference manifest and checkpoint selection are finalized on validation data.
The appendix records reference characters, bank eligibility, sampler, and provenance.

\paragraph{Training settings.}
The current joint experiments use eight V100 GPUs, eight samples per device, FP16 arithmetic, and gradient clipping at 1.0.
The effective main-task batch size is 64.
The denoiser and inherited structural modules use a peak learning rate of $2\times10^{-5}$; the local reader and router use $10^{-4}$.
Joint training runs for 10,000 successful updates, with 500 warmup updates, a plateau through update 5,000, and cosine decay to 10\% of the peak rate.
The auxiliary experiment adds 32 Chinese examples per update and starts independently from the same parent weights.
EMA weights are evaluated every 2,000 updates.
Complete resolved settings appear in Appendix~\ref{app:repro}.

\subsection{Comparisons and measurements}
External comparisons cover conditional diffusion (FontDiffuser), cross-language transfer (FTransGAN), font-bank content fusion (CF-Font), and fine-grained reference attention (FSFont).

We compare dynamic combination with fixed Mean-Delta weights over the same retrieved candidates.

\section{Discussion}
The two conditions provide different forms of information.
Dynamic Delta brings target-character examples into the generator's content coordinates and adapts their combination during synthesis.
TC learns a target-specific spatial appearance prediction from observed references.
Their combination gives the generator a structural prior and a supervised appearance destination.
The contribution studies measure how these roles translate into image quality.

The current representation operates on $96\times96$ raster glyphs.
Spatial appearance supervision connects local reference evidence to target locations.
The denoiser integrates this evidence into complete strokes, terminals, and decorative patterns.
Bank coverage also determines the available examples for rare target designs.
Extending the formulation to higher-resolution glyphs and complete typographic layout is a natural next step.

\section{Conclusion}
\method frames cross-script font generation as coherent family completion.
Dynamic Delta provides an adaptive bank-supported variation prior relative to neutral content, and target-character appearance completion predicts how local reference observations apply to the requested glyph.
The accompanying evaluation separates identity, reference consistency, and family compatibility.
Together, the formulation and two conditioning components establish a practical framework for extending a font's visual language across scripts.

\paragraph{Implementation details.}
VGG inputs use ImageNet normalization; the teacher is adaptively pooled to $12\times12$ and standardized using clean training-target channel statistics.
Joint stages load the same parent checkpoint and create a new optimizer and scheduler.
The local encoder is a trainable copy of the first three global-style encoder blocks.
Reference attention uses normalized 64-dimensional query/key heads with FP32 logits and softmax.
Delta uses 32-dimensional routing features, with $1\times1$ hidden/content projections and a $3\times3$ candidate projection.
Its time embedding maps $[t/1000,(t/1000)^2]$ through a two-layer MLP; the routing strength starts at 0.1.
EMA decay rises to a maximum of 0.999, and the completion coefficient and local attention contribution ramp over 1,000 updates.

\section{Cross-Script Compatibility Evaluation}
\label{app:evaluator}
The current E12-b encoder $\phi$ is a ResNet-18 trained from random initialization on paired Chinese and Latin ground-truth glyphs.
It maps each $96\times96$ image to a unit-normalized 512-dimensional feature.
Training uses symmetric cross-script InfoNCE at temperature 0.07.
The scorer's data are drawn from 223 usable fonts in the generator's training partition; the generator's validation and test font files are excluded from scorer fitting.
The internal scorer split contains 156/33/34 font files for training, validation, and testing.
For a scoring reference set $\Rset_f$, define
\begin{equation}
 p_f=\frac{\sum_{r\in\Rset_f}\phi(r)}{\|\sum_{r\in\Rset_f}\phi(r)\|_2},
 \qquad S(\hat y,\Rset_f)=\frac{1+\langle\phi(\hat y),p_f\rangle}{2}.
\end{equation}
The score evaluates compatibility with the supplied references and requires no target image at scoring time.
Its retrieval study ranks Chinese reference prototypes using Latin glyph queries.
Its verification study compares same-font and different-font pairs.
The primary encoder study covers 52 Latin letters; script-specific validation accompanies extensions of this score to other target scripts.

A separate membership head combines query features with mean/max-pooled reference features and predicts same-font membership.
Its temperature is fitted on internal validation data; we treat this probability as a supplementary diagnostic.
Human evaluation measures visual agreement on generated outputs through blinded, paired judgments and font-clustered uncertainty.
Numerical evaluator validation and generation results will be added after the current protocol review and paired evaluation are finalized.
