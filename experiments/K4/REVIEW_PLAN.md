- **K4-C vs K1：**同样 10k 更新预算下，扩充训练数据及其合法 donor 库后的整体收益。新增细节标签是数据适配的一部分，不能宣称仅改变了图像数量。
- **K4-B vs K4-C：**共同父权重、训练数据、donor、主任务采样、初始化、步数、推理协议均相同，唯一训练干预是 K3 辅助损失。这是判断风格监督是否有效的主要对照。B 有额外计算量，因此是相同主任务预算比较，不是相同 FLOPs 比较。

- **K4-A vs K4-C：**比较顺序适配和联合训练两种路径。A 相对共同 K0 已经历 K1 的 10k＋本轮 10k，C 只有本轮 10k；不能把该差异解释为等预算的训练路径因果效应。

K4-B/C 均从 K0 开始，不能分别从 K3/K1 接着训练。原 K1/K3 run 名中的 `V0917` 是运行命名；它们实际使用的是 0913_clean，不能误认为已经训练了此次 0917 增补数据。

## 2. 冻结训练配方

三组使用 8 张 V100、每卡 batch 8、global batch 64、seed 3407，每组 640,000 个主任务 episode。每次更新按西文/假名/注音分配 32/24/8，其中已确认细节字体配额为 19/14/5；配对与字体均衡采样沿用 KSampler。`32` 是每个 batch 的西文样本数，不是字符表大小。

训练参考从该字体实际存在的中文 StyleImage 中随机选 1–8 字。任务仍是中文参考到西文/假名/注音；不在此次比较中加入中到中或西到中。Es/Ec 冻结，teacher 归一化统计沿用同一 K0 来源。

主损失保持 epsilon MSE、VGG 0.01、offset 0.25、completion 0.01、detail 0.05；joint CFG drop 0.02、source drop 0.05。继承参数峰值学习率 2e-5，Reader/新 router 峰值 1e-4；500 步学习率 warmup，至 5k 保持峰值，之后 cosine 到 10k 的 10%。FP16、全局梯度裁剪 1、EMA 与原方案一致。

**K4-A 是新一阶段的权重 warm-start，不是原 K1 原地 resume。** 从正式 K1 最终 EMA 加载全部可训练组件，保持冻结 encoder；新建 optimizer/scaler/LR 周期与采样状态。TC 的 beta 保持成熟值 0.8，completion/detail 保持全权重，不重置为零重新爬坡；仅学习率重新 warmup。新 EMA 从所载 K1 EMA 初始化。这样不会在阶段切换时暂时关闭已经学好的条件分支。若本阶段中断，恢复的是 K4-A 自己的完整训练状态。

K4-B/C 具有相同的初始参数张量与主任务 episode/noise/drop 序列，保留原 1k TC/主损失 ramp。K4-B 使用隔离随机数的辅助采样，不消耗主任务随机数。

**K4-B 辅助监督严格沿用 K3：**每 16 个成功更新一次，全局 8 对（西文/假名/注音 4/3/1）；同字符、不同字体、同参考字集合、同一纯噪声；8 步确定性 DDIM 完整反传。损失为 GT 区域重建与预测差异相对 GT 差异的约束，不引入可学习的 SCR 判别器。首个有效训练辅助 batch 以共享 UNet 梯度 10% 标定系数，裁剪到 [1e-6, 0.5] 后冻结，辅助项 500 步 ramp。10k 更新共 625 次辅助事件、5,000 对、10,000 个完整生成样本。

定期保存完整 model/optimizer/scaler/RNG/EMA/采样与数据身份；每 1k 保存状态并保留两份滚动状态，2k/4k/6k/8k/10k 保留 EMA。每 2k 观察固定 v2 Val192，不据质量提前终止或选择某个更好的 checkpoint；主报告统一最终 10k EMA。硬件、NaN、错误 GT 或续训身份异常才停止并保留故障证据。

## 3. 启动前必须补齐的数据适配

以下是已从当前代码确认的适配缺口，不是新训练已发生的错误：

1. **数据路径和缓存目前锁定 0913。** `h_runtime.args_for`、缓存校验与 runner 需显式绑定各组数据 manifest、checkpoint 和缓存增量，不能只改目录字符串。旧 Es/Ec 特征可按 encoder/输入哈希复用；新字体增量编码。v2 查询字体的参考特征可以预计算，但 val/test 目标不能进入训练 donor 库。
2. **donor 必须逐字符且逐参考集合合法。** 当前 `extra_exclude_indices` 只有粗 script 过滤，不足以处理 0917 部分 Latin-Ext 缺字。候选集合应为：本组 train 中拥有该目标字合法 GT、拥有此次全部参考字、且不是目标字体的 donor。先过滤有效键再构造 prototype，不用缺字或其他脚本替代。保持原 alpha/top-k 公式。
3. **旧 prototype 假设每字体都有 338 个中文参考字。** `_LibraryEs` 会为所有字体读取同一 338 字表；4 个新增字体不满足。改为存在性掩码/有效 donor 子集，并保持同一参考集合用于 query 与 donor。推理 loader 也必须在读取样本时使用清单参考字，不能先按旧固定 ref8 读取失败，再事后覆盖。
4. **必须扩展“已确认细节”训练标签。** 旧标签只覆盖 0913 的 22 个 font-script 组。新字体若全部按默认未确认处理，B/C 的细节配额会继续集中在旧字体；A 更会因确认池为空无法构造原 sampler。训练前按同一视觉口径审阅 0917 train 各合法脚本的 GT 面板，记录空心/描边/装饰/局部结构等证据，保留旧标签、冻结新标签及审阅来源。未确认不等于简单，也不能直接把几何难度高当作视觉复杂。A 用新标签子集，B/C 用同一合并标签。
5. **K3 配对保持参考字交集与去重。** 两字体都必须有同一目标字、真实 GT 差异及足够共享参考字。合并旧 alias 与新 split grouping，排除已知同源/重复对，不按不同文件名假定不同风格。

冻结前先审计完整 10k 采样计划，按来源×脚本×细节类别统计字体和字符覆盖，确认 0917 确实得到曝光。B/C 不另加 50:50 来源配额，沿用原字体均衡机制；不把文件数比例误当作实际曝光比例。若新标签不足以满足原配额，应在启动前报告具体缺口，不能默默降配额或伪造标签。

预检包括所有合法 pair/参考/候选 donor 的存在性、缺字字体路径、1/2/4/8-shot、B/C 主采样序列一致、K3 辅助全路径梯度、8 卡参数同步与 AMP、完整断点恢复、旧字体新旧适配器推理对齐。只做这些工程检查，不先挑效果好的版本再定义实验。

## 5. 复用规则与已核对数量

**可以复用：**K0/K1/K3 权重、旧输入图像、encoder 身份一致的旧特征、旧结果的独立历史展示，以及严格匹配的 K0 1-shot 预测。

已核对 **2,336 张 K0 1-shot 候选**（val 528、test 1,808）：文件存在、文件 SHA256、字体/字符/shot/refs/noise seed 对齐。正式复用还需新 K0 适配器与冻结后端对齐、输入与全部组件哈希一致、同一数值/采样协议；失败则重算对应图像。K0 不使用 Delta，新增 donor 库不会改变其条件。

**K1/K3 旧默认 val/test 各 9,344 张不进入新的主评测复用池。** 虽然 checkpoint、字符和噪声可一致，但 donor 库扩充会改变检索与 alpha，因此它们不是同一条件的预测。旧库协议的原图和分数保留为独立历史结果。仅对 K0 候选通过最终适配检查的情况下，主任务预计新生成 **300,463 张**；已保存逐条候选路径和哈希，无需复制旧 PNG。

其余将来的断点续推按任务身份和图像哈希复用，身份包括 checkpoint/EMA、所有冻结 encoder、输入图像、refs、seed、donor 规则/库/实际选取及 alpha、sampler、CFG、步数、代码与精度。`index` 或文件名相同不能作为充分依据。逐图指标可以在评价器与 GT 哈希不变时复用，完整 v2 汇总必须重算。

## 6. 汇总、判断与展示

主表分 val/test，至少按 **来源 0913/0917 × shot × script × 难度** 输出，并列样本量与字体数。西文继续拆大写/小写/数字/扩展，假名拆平/片。主聚合采用先字符再字体的 font-macro，另提供 pair-micro；总分另列来源/脚本平衡版本，避免覆盖较多字符或字体的组支配结果。无该脚本的字体记 NA，不计零。

延续 LPIPS、L1、SSIM、D_region、D_change、D_high 和冻结 E12-c Family 等已有指标。Family 保持辅助地位，不把它当正确率；需单独报告评价器在 0917 GT 上的适用性，不能因换了数据就默认相关性有效，也不能用新 test 调评价器。生成质量判断结合可读性、局部风格、参考响应和完整图像，不能仅凭训练 loss 或 GT 像素误差。

难度沿用已冻结的 GT 几何 proxy：保留 0913 train 的逐字符参考分布与阈值，应用于新数据；标明是几何重绘需求，不冒称人类风格难度。该分层与训练用 confirmed-detail 标签分开，不用预测分数来分组。

报告 K4-B−K4-C、K4-C−K1、K4-B−K3、K4-A−K1 的配对差值；K0 的公平主比较只在 1-shot 内，2/4/8-shot 表不伪造 K0 行。可在可视化中重复展示同一 K0 1-shot 供参考，但明确标签。对差值以字体/已知 lineage 分组 bootstrap，报告区间，不把大量同字体字符当独立样本。训练仅单 seed，区间不能代表跨训练 seed 稳定性。

重点同时看 0917 收益和 0913 是否退化，不能用总体均值掩盖遗忘。保留旧 split 已有的同家族跨 split 历史问题，补一个剔除已知重叠家族的敏感性表；不改既有划分、不声称绝对 lineage 隔离。相对 K1 的变化还包含新增训练库/标签/数据多样性，叙事按实际干预范围写。

最终页面同屏 Content、参考字、GT、K0 1-shot，以及 K1/K3/K4-A/B/C 的 1/2/4/8-shot，按 split/来源/字体/字符/脚本/难度筛选。保留全量逐图 CSV、聚合表、来源/seed/缓存证明和失败/复用日志。
