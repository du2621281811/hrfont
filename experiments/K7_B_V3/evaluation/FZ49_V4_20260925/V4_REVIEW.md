## L1 批量复算

对 17 组 × 8,638 个 V4 样本（共 146,846 张预测图）逐张计算 L1：灰度化、96×96、像素归一化至 [0,1] 后取平均绝对误差。对原先已有逐样本 L1 的 16 组，原值与复算值最大绝对差为 0.0671，平均绝对差为 5.66e-05；超过 1e-6 的 1,526 条。最新 FontDiffuser release 的 L1 是本次直接计算的，没有单独的输入 L1 值参与一致性审计。原值与复算值审计见 `all_methods_l1_audit.csv.gz`。

## Target 快照一致性

只比较相同字体×字符还不够：V100 的 shot 推理使用独立数据快照。只读哈希核验发现其部分 target PNG 与 K7-B 公共测试真值不同，因此已在 V4 公共 target 下重算受影响的 target-dependent 指标。

| 方法 | 源 target 不同样本（全量） | V4 中统一重算行数（L1 / SSIM / LPIPS / DINO） |
| --- | ---: | ---: |
| shot_1 | 384 | 8,638 / 362 / 362 / 362 |
| shot_2 | 384 | 8,638 / 362 / 362 / 362 |
| shot_4 | 384 | 8,638 / 362 / 362 / 362 |
| shot_8_alt | 473 | 8,638 / 440 / 440 / 362 |

分方法、分字体和数据阶段的哈希计数见 `v4_provenance.json`；受影响的逐样本修正值与 target 不一致标记见 `v4_target_alignment_audit.csv`。为避免泄露机器目录，Git 包不保留源/公共 target 的绝对路径。V4 每样本表同时保留 `*_input` 原分数以便逐行比较。

其中，V4 内源 L1 与共享 target 复算值相差超过 1e-6 的样本数为：shot_1 362; shot_2 362; shot_4 362; shot_8_alt 440；其他 12 组均为 0。

## 解读边界

- 以上排名是 V4 固定评测面板上的描述性比较，不是显著性检验，也不能单凭指标排名判定样本/真值有误。
- `shot_1/2/4` 是标准参考集的嵌套 shot 设置；`shot_8_alt` 的参考字不同，不应并入同一条 shot 数量因果曲线。
- 外部基线、路由变体、结构/条件消融回答的问题不同。跨组总排名用于导航，不等同于受控归因结论。
- L1 全量从预测图与共享 K7-B 真值图复算。FontDiffuser release 的 8,638 个样本均按相同协议计算五项指标；其普通发布图部分的 L1/SSIM 与此前逐样本结果在 8,260 个重合样本上完全一致。shot 组存在独立 target 快照的样本，SSIM/LPIPS/DINO 已对齐到同一 K7-B 真值图后复算；其他原有分数沿用已验证的评测流程，RSC-8 与真值图无关。LPIPS/DINO 与合作者端私有脚本未做逐行协议复现。
- 原始 FZ49 文件未修改；评测结果、样本清单及 provenance 记录在本目录。
