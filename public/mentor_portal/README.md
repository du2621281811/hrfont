# HR-Font mentor portal

只读静态评审入口，公开内容被服务端路由限制为：

- `/`：整理后的项目入口；
- `/rendering.html`：六种渲染协议与边界框解释；
- `/bbox/`：原始边界框技术页；
- `/e1/`：E1 正式交互评测；
- `/assets/`：周报精选图片。

启动：

```bash
python scripts/serve_mentor_portal.py --host 0.0.0.0 --port 19001
```

本机检查：<http://127.0.0.1:19001/>

服务器已允许外部访问 `19000–19002` 时，使用 `19001` 直接提供 Portal，并将
`http://<服务器地址>:19001/` 发给导师。若仍通过 Cursor 隧道访问，则在
**Ports** 面板转发 `19001` 并设为 **Public**。公开期间不要把服务根目录改成
项目根目录或 `data/`；评审结束后关闭服务或端口转发。
