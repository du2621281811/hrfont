# I3 / I4：视觉细节 TC 与中文辅助监督执行计划

更新：2026-09-16。状态：**新实现、数据分桶、端到端预检均通过，正式I3→E12-c→I4队列已派发I3**。详见[执行手册及验收](I34_EXECUTION_RUNBOOK_20260916.md)。本文件是I3/I4统一规格，替代“低相似度样本降权”的早期建议。I0/I1/I2两协议推理已全部完成归档，旧运行程序未修改。

## 1. 目标、关系与贡献

目标是在白底黑字的跨语种生成中，加强笔端、粗细、飞白、镂空与装饰结构的保留。Delta 继续提供潜在结构变化空间；TC 根据中文参考和目标内容补全目标字风格；任务定义及评测保持原故事。新损失和采样属于方法训练设计，不另列为独立贡献。

| 模型 | 初始化 | 主任务 | 中文辅助 | 预算 |
|---|---|---|---|---|
| I0 | 指定 G0b@10k | 已有预训练底座 | 不新增训练 | 复用 |
| I3 | I0；I1 架构的新模块重新初始化 | 局部 TC + 动态 Delta + 直接 token 细节监督 + 校准难例采样 | 无 | 新增 10k 成功更新 |
| I4 | 同一个 I0，与 I3 相同架构和初始新模块权重 | 与 I3 完全相同 | 沿用 I2 的中文留一目标任务，并应用同一新细节监督 | 新增 10k 成功更新 |

**I4 : I3 = I2 : I1。I4 不继承训练后的 I3；I3/I4 不继承 I1/I2 的训练权重。** 两臂共享同一数据分桶版本、主任务采样/噪声规则与超参数。使用独立 RNG 流隔离辅助任务，避免中文采样额外消耗 RNG 导致主任务计划不同。I4 额外计算量需单独记录，不写成等算力比较。

本轮只排 I3、I4；不排“去分桶”“恢复旧 TC”消融，不加矢量 decoder、GAN、外部字体或合成风格增强。

## 2. 校准难度，而非按相似度筛选好数据

PI 的目标是增加难例曝光。低跨语种相似度可能来自真实迁移困难、字符风格证据不足、Es 的表示偏差或跨语种字体错配。不能直接用 cosine 越低、权重越大的规则。

### 2.1 离线评分流程

1. 只使用 0913 有效训练字体及字符；val/test 不参与评分标定、阈值选择或采样。冻结 I0 Es 作为低成本离线特征，不训练新的难度模型。训练 GT 仅用于采样元数据，不进入生成器条件或改变 shot 信息预算。
2. 为每个字体构建多组、内容尽量一致且覆盖方向/曲线/交叉/复杂度的中文字符面板，归一化特征后稳健聚合。记录字符列表、Es SHA 和数据 manifest SHA。使用全部可用缓存或固定上限的共同面板，具体面板随采样 manifest 冻结。
3. 对目标字符 c，比较其与本字体中文原型和其他字体中文原型的匹配，得到相对匹配排名/间隔。负例字体集合在相同字符的比较中保持一致。
4. **同字符校准**：只在不同字体的同一个 c 上将难度转换成经验分位数。U 与其他字体的 U 比，不直接与复杂字形比较。原始匹配间隔同时保留，防止只看相对分位数放大几乎相同的噪声。
5. **风格可观察性**：在目标语种内部，用字符 c 匹配该字体其他字符的原型，构建原型时排除 c。若该字符在同语种也难以区分字体，其跨语种难度证据应降低置信度；这是 Es 可读性诊断，不等同于字符客观上没有风格。
6. 按字体×目标语种稳健聚合多个字符的校准分数；中文子集和目标字符子集重采样检查排名稳定性。Latin、假名、注音分别建桶，假名额外记录平/片假名诊断；不整体删除某个字体。
7. 对约 30–40 个覆盖易/难/极端/特殊风格的字体—语种面板快速人工复核。确认的错配按既有映射排除或提请 review；自动评分不擅自改动冻结的清洗映射。字数太少、同字符可比字体不足、排名不稳定的样本标为不确定，保持基础曝光。

难度是静态代理，不宣称已证明等于模型学习难度。首轮不做在线 loss mining。易/中/难初案为各语种内可信字体组的三分位桶；最低可比数量、可观察性和稳定性门槛须在离线复核后冻结并记录，不在训练中悄悄调整。评分若不能通过复核，应报告阻塞并 review，而非静默改成另一种采样。

### 2.2 采样

- 语种外层沿用 Latin/假名/注音 = 0.50/0.38/0.12；shot 与 ref 选择规则不变。
- 每个语种内，难例分布为 `p_hard(x|g) ∝ p_old(x|g) × w(font,g)`；易/中/难权重 `1.0/1.5/2.0`，不确定为 `1.0`。
- `p_s = (1-lambda_s) p_old + lambda_s p_hard`。前 1k 成功步 lambda=0；1k–2k 线性增至 0.5；之后保持 0.5。
- 权重作用于字体—语种组，组内保持原均匀字符抽样。不重复给 loss 乘难度权重，不特意挑最差 ref。
- 上述有限倍率与 50% 原采样保留覆盖底座；监测每字体及特殊风格曝光，不叠加第二套稀有风格强倍率。
- I3/I4 主任务使用同一冻结分桶文件；I4 的中文辅助不套用跨语种难度分数，沿用 I2 中文采样。

产物已生成并冻结：[difficulty_manifest.json](experiments/I/preflight_i34/difficulty_manifest.json)，以及同目录 `difficulty_char_scores.json` 和3张审核面板。含541个字体—语种组，易180/中181/难180；阈值、原始/校准分数、字符可观察性、两类半样本稳定性、权重和源SHA均可追溯。

## 3. 两臂共享的 TC 与监督改动

当前 `LocalMemory` 是 `out(U)` 供生成器使用、`readout(U)` 对齐 VGG teacher。共享 U 可获得监督，但 teacher 项未直接约束 out 投影。I3/I4 替换旧 TC teacher 目标，不改变 Delta 结构或候选组合权重机制。

### 3.1 直接监督生成器实际使用的 token

- 保留在线多尺度 ref 编码器、目标 neutral content 查询、144 个局部 tokens 和既有注入位置。
- 在 `A=out(U)`（B×144×1024）上接共享 Linear(1024,64)，sigmoid 得到每位置 8×8 灰度 patch，按 12×12 token 网格拼成 96×96 预测图。
- 约 65,600 个训练期参数；推理时移除该读出头。不是额外推理 decoder。
- 读出只看 A；A 只来自 ref 和 neutral content，不接收 GT、带噪 target 或 GT teacher 输入。目标图只作为监督。
- 老 TC VGG readout 损失删除；原生成图 VGG 感知项保留。检查 token/patch 坐标、灰度范围、CFG mask 以及梯度确实经过 out/attention/online encoder。

### 3.2 细节距离与联合损失

对 96 与 48 两个尺度计算 `D = D96 + 0.5 D48`，每尺度 `Dq = weighted_L1 + 0.5 weighted_Sobel_L1`。target 灰度保留抗锯齿；用 GT 墨迹与内外轮廓邻域构建有界权重，背景仍为正。初案背景权重1、墨迹及边界合计不超过5，按权重和归一化。Sobel 固定归一化核，边界带宽1–2像素；实现时固定阈值/带宽进配置，两臂一致。不得硬二值化/膨胀 target 本身。

`L_task = L_eps + 0.01 L_VGG + 0.25 L_offset + ramp(s) [0.02 D(TC_readout,y) + 0.05 w(t) D(x0_raw,y)]`

- ramp 前1k从0增到1。权重是拟议初值，短预检校准后两臂共同冻结。
- `w(t)=SNR/(1+SNR)=alpha_bar_t`；不改变原始 timestep 抽样。
- 新两项仅作用于 conditional 样本；批内归约分母明确固定为该任务 batch 大小，unconditional 样本贡献0，避免有效样本数变化造成倍率漂移。
- epsilon 参数化下 FP32 计算 `x0_raw_norm=(x_t-sqrt(1-alpha_bar_t)*eps_pred)/sqrt(alpha_bar_t)`，再映射至灰度域；新细节损失前不硬 clamp。原 VGG 路径不随此更改。
- 不用边缘指标单独定义成功，最终要看正式生成图是否保留真实笔触而非统一锐化/噪点。

## 4. I4 中文任务：唯一新增因素

- 数据复用已批准的 `v0913_clean+I2_CN_Noto83_Pillow12.2`，338 字 neutral content 及 Ec 特征，执行前核对 COMPLETE 和哈希；不重新渲染、不改变主任务 0913 PNG/缓存。
- 使用有效训练字体：同字体中文 refs → 不同中文目标，refs 必须排除目标字。不得混入 val/test 字体。
- 共享同一个 TC、生成器和训练期读出，不增加中文专用网络。
- 中文分支 Delta 的实际 offset 输出置零，与 I2 一致；主分支 Delta 正常。
- `L_I3 = mean_64(L_main)`。
- `L_I4 = mean_64(L_main) + 0.5 mean_32(L_CN)`；中文项使用上节相同 TC/输出细节目标和同一 ramp。两任务每次成功更新一起回传，单次 optimizer/EMA 更新；不把64主任务样本改成32。
- I4 每步多32个中文目标，与 I2 同配比，额外计算量另记。主辅 loss、梯度、曝光计数分别记录。

## 5. 训练预算、顺序与准入

统一每臂8×V100、10k成功更新；主任务每卡8/global64；I4另每卡4/global32中文。继承主干峰值LR2e-5，新/在线模块1e-4；500步warmup，5k后cosine至峰值10%；沿用现有AdamW、FP16+GradScaler、clip1和EMA，不切换BF16。冻结的 Es/Ec 与可训练 online encoder 边界不变。

排程：

1. 完成当前 I2 k1248 → 缺失 I0 formal4096 → 验收归档；旧队列退出且锁释放。
2. 完成独立新实现、分桶人工复核和冻结配置；CPU数据检查、小样本过拟合、8卡短预检和恢复检查通过。
3. I3 10k → 原 formal4096（val）→ 同款 k1248（4888图，train/val/test分开）→ 归档。
4. E12-c轻量两阶段训练及自动内部验证/归档（2000+1000成功更新，默认1卡）；不等待后续人评。
5. I4 任务边界短预检 → 从同一 I0 独立训练10k → 同上两协议推理 → 归档。

实现/数据/8卡/恢复/实际推理验收已通过；新队列持有旧实验同一把互斥锁。PI批准新checkpoint放data1，空间预算和两个文件系统10GiB停止线见执行手册；未清理旧模型。
