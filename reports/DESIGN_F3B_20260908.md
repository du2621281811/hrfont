# F3b 设计与执行规格（2026-09-08 review 后执行版）

run id：`f3b_joint_crossbank_s3407`。定位仍为方法完整形态：Δ 检索残差 + 跨字体双门 support + 多尺度 style 条件。本文给出可以直接实现的默认值；先 20k 看增量，再推进 80k。新 F3b 模块/缓存由执行机实现，本次提交修复现有 F3 adapter 梯度并统一执行文档。

## 1. 对比对象与现有 F3 修复

| 变量 | F3 现有实现 | F3b |
|---|---|---|
| support 字体 | own-font | α top-10 邻域，排除 self |
| 选字 | 固定 8 字 | 目标字符拓扑相关 CN 字 |
| 注入 | SupportAdapter token 拼入 up-path style attention context | 独立 support cross-attention，mid-block 起 |
| style | 9 个全局 token | 9 全局 + 64 局部 token |

F3b vs F2 衡量 support 完整机制与 style 加细的组合增量，不声称每项独立创新。

当前仓库 F3 原先在 `torch.no_grad()` 内调用可训练 SupportAdapter；本次已将调用移到其外，保留 cache-only。旧 adapter 为零输出初始化，因此旧运行若使用同一代码，其 adapter 不会更新。执行机核对旧 run 的代码/adapter checkpoint，保留为历史结果并标注状态即可，不阻塞 F3b 实现。若需要有效 own-font F3 消融，用修复版从同一 F0 新建 run；不覆盖旧结果或把修复后的续训混称原 matched run。

F1/F2 的训练路径不受此梯度修复影响。F3b 的新模块仍按 PI 决定使用标准随机初始化，不继承旧 SupportAdapter 的 zero-init。

## 2. 双门 support：明确采样轴与 token

- 字体集合 J：沿用 Δ 的同一组 α top-K 索引，K=10、τ=.07，bank=train228，排除 self；每样本只算一次并共享。α 用于选字体，support 特征沿字体轴等权聚合。
- 字符集合 C16(c)：中性 B0 的目标字符 c 与 CN style338 的拓扑相关性 top-16。相似分数下降排序，平局按 Unicode 升序；不避 ref8。
- 原始候选是 J×C16 的字形对。对每个 CN 字 r，读取 J 中各字体的 `Ec(style,font,r)`，逐尺度 spatial mean 后 concat 为 D=707 向量，再沿字体轴等权均值。得到 **16×707**，保留字符轴，不将全部字符池成一个 token。
- 训练在 C16 中无放回随机选 k_s，k_s~Uniform{4..16}；推理固定拓扑排名前 8 字。这里 k_s 计数字符，不是 160 个字形对中的抽样数。
- 若数据存在缺字，先使用实际可用字体聚合；无可用字体的字符移出候选并记录。剩余不足 4 字时全取；池空则该样本关闭 support。正常完整缓存应有 16 字，不依赖 fallback。
- 投影到 context_dim 后形状 `[B,k_s,D_ctx]`；padding 提供 attention mask。全缺省/被 drop 的样本直接令 adapter 分支输出为零，避免全 masked softmax NaN 与投影 bias 泄漏。

## 3. 拓扑表默认实现与验证

B0 渲染 target295+style338，固定前景阈值与 thinning 实现。默认签名：孔洞数、8-connected 连通域数、骨架端点数、合并相邻交叉像素后的交叉簇数、8-bin 无向骨架方向直方图。计数用 log1p 后按 B0 全表固定尺度归一化；方向直方图 L2 归一化。各计数维度合计权重 0.5、方向块权重 0.5，以加权拼接后的 cosine 排序；保存公式、实现版本、B0 字体 SHA、签名与 C16 表 SHA。

先输出每类 script 的目标字及 top-16 CN 面板，查看选字是否能提供相关笔画。P0 用同一 checkpoint 比较相关/随机/低相关三组，固定字体集合、support 数与输入 RMS；若有信号再跑 20k 相关/随机 matched 训练。该验证与 style on/off 使用同一验证题集，不使用 test 挑表。

## 4. 注入、drop 与 RNG

- Q=UNet hidden states；K/V=多个 support 字符 token。新增独立 cross-attention residual，首轮固定 mid-block；先完成此版本，后续确需比较位置时另记候选配置。
- 新 adapter、投影与输出层采用框架标准随机初始化，不 zero-init，不加早期抑制 schedule。记录输出 norm、梯度 norm、参数更新 norm。
- 训练 support 生效条件：非 source_drop 且非 support_drop 且非 CFG-drop 且有有效候选。source_drop=.25 与 Δ 共享；support_drop=.20 独立抽样；CFG-drop=.10 时新 support 分支与局部 style 分支同时关闭。
- 原有 F2 的 Δ/source/CFG 行为沿用，不在 F3b 中顺手改动。新分支的 CFG 关闭属于其条件协议；推理 unconditional 对新分支同样关闭。共享旧分支用同一 F2 推理实现，固定 sampler/CFG scale/seed。
- support 选字使用独立 RNG（seed、样本 id、step 确定），不能消耗 noise/timestep/source/CFG 的共享 RNG。新模块初始化也隔离 RNG；off 臂保留相同初始化/draw 消耗或使用独立 generator。记录首批配对样本、noise/timestep/drop 摘要。
- frozen cache 读取可在 no_grad 中；所有可训练 projection/attention 均在梯度图中。首次训练验证参数确实更新，不以 loss 能反传代替 adapter 梯度检查。

## 5. 多尺度 style：缓存与消费点

现有 Es cache 只有最终 3×3 map 与 pooled vector，不能从中恢复局部笔画。新增 `es_local_f0` 缓存，使用同一冻结 F0 Es：

- global：继续旧 1024×3×3 map，8 refs 平均后展平为 9 token。
- local：取 96px encoder 第三个 down block 的 **256×12×12** 中间特征（实际 shape assert），每个 ref 自适应平均池化到 8×8。保存冻结特征；训练时每个 ref 投影后沿 ref 轴平均，得到 **64 local token**。
- concat 得到 73 token；局部投影使用标准随机初始化。新 token 接入现有 style cross-attention 的 down/up 消费点，不假设 `unet_blocks.py:227` 接受 3D token；明确保留旧 map 与新增 token 两个参数。
- 缓存 manifest 包含 F0 Es SHA、层号、原始/保存 shape、dtype、渲染与 split SHA、payload SHA。覆盖主实验实际使用的 ref 字池；Es/Ec 在正式训推中继续 cache-only。
- 首轮固定 64 局部 token；128 属于后续容量候选，不在首轮引入额外搜索。
