## 1. 相对 F3 的变量清单（诚实声明）

F3b ≠ F3 的单变量扩展，共 4 个变量：

| 变量 | F3（已跑完） | F3b |
|---|---|---|
| support 字体来源 | 同字体（own-font） | **α top-K 邻域（跨字体）** |
| support 选字 | 固定 8 字（优先 ref8） | **双门：风格相似 + 目标字符拓扑相关** |

| style 条件 | 9-token（3×3） | **多尺度 token（9 全局 + 64-128 局部）** |

贡献拆解（预注册）：style 加细 → 20k on/off head-to-head；拓扑 map → P0 推理期三变体 + P1 20k 相关/随机（信号成立才做）。F3（own-font support）保留为中间消融臂。

## 2. support 机制

- **字体门（风格相似）**：α top-K（K=10、τ=0.07，与 Δ **同一 α、同一 draw、同一 source-drop mask**）；**显式排除 self**。
- **字符门（结构相关）**：中性字体（Noto/B0）上计算拓扑 primitive 签名（孔洞数/连通域/端点/交叉点/主笔画方向）→ per-(target char, style char) 相关性表（char-level 静态、离线预计算一次、训推同一张表）→ 每 target char 取 top-k' 结构相关 CN 字（k'=16 候选池）。
- 候选池 = 双门交集；每样本随机抽 k_s（训练 k_s~Uniform{4..16}，推理固定 top-8）；池空 → support dropout（该样本不给 support，训练时即鲁棒性）。
- **不避 ref8**（train/test 隔离的是 style，content 复用合理）。
- 特征 = **Ec**（`ec_cache.features("style", font, cp)`，per-scale spatial mean → concat）；**等权池化**（α 近均匀实证，加权≈等权且省 Es 精度依赖）。
- 错误风格控制：双门 + dropout + K 截断；E9 预注册 wrong-style swap 探针（RMS 控制）；训练前先离线审计 α 邻域错误风格率（独立风格度量，非 Es 自证）。

## 3. support 注入：IP-Adapter 式解耦 cross-attn

- 解耦 cross-attention：K/V 来自 support 特征投影，Q 来自 UNet 特征；注入位置以 20k 筛查定（mid-block 起）。
- **无 zero-init、无防御性初始化**（PI 拍板 2026-09-08）：adapter 全新模块标准随机初始化，80k 预算吸收早期噪声；日志记录 adapter 输出 norm 早期曲线（观测不干预，`rsi_gain` 的 support 版读数）。
- 机制复用 IP-Adapter（citation 现成），创新点留在「喂什么证据」；与 Δ/RSI 物理分离。

## 4. style 条件加细

- style encoder 池化前的空间特征图 → 投影成 64-128 局部 token，与 9 全局 token 拼接进 style cross-attn（unet_blocks.py:227-230 现有消费点）。
- 投影层随机初始化（不防御）；F1/F2/F3 若后续也加则统一加（当前仅 F3b）。
- 预期：ref 特有特征（连笔/笔触）保真中等偏上改善；风险低（风格流与内容流分离）。

## 5. matched 契约与对比链

- F3b 与 F2：同 F0 初始化、同 head_seed/RNG/drop 契约；F3b vs F2 = support 机制（完整版）+ style 加细的组合增量。
- F3b vs F3：own-font→跨字体双门 support + 注入点 + style 加细的组合。
- 推理 cache-only 铁律不变（Es/Ec 全离线，与 Δ 同 cache）。
