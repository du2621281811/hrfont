# G2 / G2-RL：参考证据聚合与 TC 实验计划

状态：2026-09-14 用户已批准同步与执行。方法规格如下；实际实现、验证、启动情况以文末执行记录及队列状态为准。
本稿调整上一版方案的执行优先级：先验证两条主干共用的 ref 聚合，再验证 TC 的增益；细节监督 D 和空间 TC 保留在 [后续选项附录](G_STYLE_DETAIL_OPTIONS_20260914.md)，不同时启动两份计划。

## 1. 要解决的问题

保持三个贡献：跨文字任务与评测、Mean-Delta 结构变化先验、目标字风格补全 TC。弃用的 set-delta 不恢复。

本轮的工作假设是：增加 ref 的同时，也改变了证据的混合方式和条件之间的权重；模型未必能把新增的参考信息转化为更好的目标字。

不能把它简化为“所有方法都因为 token 增多而注意力涣散”：

| 路径 | 当前输入 | 更值得检验的瓶颈 |
|---|---|---|
| G2 global / down-path | k 张 ref 的 Es 3×3 特征先均值，始终是 9 个空间位置 | 不同参考字的局部形态先混在一起，后续网络无法分别读取原证据 |
| G2-RL global / down-path | 与 G2 相同 | 同上 |
| G2-RL local up-path | 16k 个 local tokens 与固定 9 个 global tokens 共享 softmax | 除上述问题外，还存在 local/global 的数量偏置 |

相似特征不等于无价值：两张 ref 可能具有相同粗细，却分别提供钩和弧线。Es 中的字符相关信息也不都应删除，它可能是笔触证据的载体。因此首轮不按 Es 余弦相似度硬剪枝，不重新训练 Es，不把全部 content 信息视为污染。

已有分析支持“ref 路径值得优先处理”，但尚未证明冗余是主要原因。G1 无 Delta 也有多-shot 回退；RL 对 G2 有部分改善；当前 TC 联合训练则没有产生正向生成增益。这些是方案的起点，不是新方案有效的证明。

## 2. 共同改动 R：先逐参考读取，再固定九槽融合

### 目的和接口

让 G2 和 G2-RL 都能在平均之前读取每张 ref 的空间证据；保留原 global9 接口和均值锚点，避免恢复效果较差的 PRL 路径。

每张参考的冻结 Es 特征写为 M_i ∈ R^(9×1024)，原始均值为 μ。新增一个小型、目标无关的读取器：

```
Q0: 9 个可学习查询，隐藏维度 128，4 heads
A_i = Attention(Q0, K(M_i), V(M_i))       # 每张 ref 独立读取，输出 9×128
A   = masked_mean_i(A_i)                 # 仅平均有效 ref
G   = μ + W_out(A)                       # 输出 9×1024
```

- K/V 为共享投影；W_out 权重和偏置零初始化，初始化时 R-only 与原路径一致。
- Q/K 可以归一化以稳定匹配；V 不做强制单位范数化，保留幅度信息。
- 九个 slot 的索引固定，无参考序号 embedding；保证对 ref 顺序置换不敏感。slot 不是目标字的空间位置，不宣称已完成目标对齐。
- G reshape 为 1024×3×3，供原 down-path 使用；同一个 G 用作 up-path 的九个 global tokens。
- G2-RL 原 local token 路径保留。R 不新增 local 信息源；因此 G2-R 与 G2 的区别确实是读取/聚合方式，而非偷偷增加局部 encoder。
- R 不读取目标 Ec、Delta、alpha 或 donor；alpha 仍由原始 ref pooled queries 计算。Mean-Delta 的公式、缓存和检索均不变。
- 首版只有上述 attention 和输出投影，不叠加可靠性网络、聚类、top-k、GAN 等改动。

为什么不同于原均值：Attention(Q, mean(M_i)) 通常不等于 mean(Attention(Q, M_i))。逐参考的非线性读取发生在信息混合之前，而不只是对已经混合的均值再加一层网络。

R 没有数学上的“自动去除无价值参考”保证。它保持固定输出大小、参考平衡，并提供可训练的读取能力；有效性由短实验决定。如果 Es 的 3×3 表征根本不含所需细节，R 也不能凭空恢复。

### 实现正确性要求

1. 冻结 Es 的特征读取可以 no_grad；R 的前向必须在 no_grad 之外，参数加入 optimizer，并在分布式包装前注册。
2. 保留逐参考 maps 和有效 mask，不能先 mean 后再假装逐参考读取。
3. CFG dropout 在 R 输出之后正确归零，不能让 bias 或学习查询泄漏到 unconditional 分支；local mask 维持原语义。
4. 新模块初始化保存并恢复 RNG，不改变配对实验的噪声、时间步和数据顺序。
5. 单测包含：零初始化 baseline parity、置换不变性、整组重复不变性、padding 不变性、有效梯度、训练/推理同构、checkpoint 加载一致性。
6. 记录实际参数量、耗时和显存，不提前将理论小模块开销写成测量结果。

若 R 明显有效，再在获益主干上追加 R-mean 控制：同一参数化读取器只读取 μ，参数量与训练预算相同。它用于区分“逐参考读取”与“多了一个小模块”的收益，不挤占首轮名额。

## 3. RL 专用改动 N：消除 local 的纯数量优势

保留原拼接 attention，在有效 local logits 上减 log(k)：

```
logits = concat(global_logits, local_logits - log(k_valid))
```

k_valid 是样本实际有效参考数，padding 仍 mask；对 local 被 CFG 全部关闭的分支不得产生 log(0)。当前每张 ref 固定 16 个 local tokens，因此上述定义成立。

在所有有效 logits 相同的示意情况下：原 local 总权重从 1-shot 的 16/25≈64% 上升为 8-shot 的 128/137≈93%；加入 N 后保持约 64%。这只是计数效应示例，不是已测得的模型 attention 分布。

N 的含义是让新增参考以证据内容竞争，而不是仅靠 token 数量扩大 local 分支占比。它不保证质量随 shot 单调提高。相同证据整组重复可用来验证数量不变性；在一组不同 ref 中只复制其中一张，仍会改变相对频率，不能混为一谈。

G2 不用 N，因为其 token 数量不随 shot 改变。R 与 N 必须有独立对照，不直接只跑 R+N。

## 4. TC：保留独立的目标字补全任务

| 模块 | 回答的问题 | 是否读取目标 content | 训练依据 |
|---|---|---|---|
| R | 这些 ref 提供了哪些可用证据？ | 否 | 原生成目标 |
| Mean-Delta | 目标字符可能沿哪些结构方向变化？ | 是 | 保留既有路线 |
| TC | 对这个目标字符，参考字体的外观应该如何体现？ | 是 | 同字体目标 GT 的外观 teacher，再接生成器 |

R 是 ref 输入接口的改善，不单列第四贡献。TC 保留独立输入、显式目标字预测及监督；不把 target-query 放进 R 导致二者功能重合。

### 先修现有 TC 的训练连接，不先扩大 head

已有 probe：预训练 H 的目标描述符误差低于联合训练后的 H，而当前 TC 图像表现弱于对应基线。优先检验“已学会的补全能力，在生成训练中被破坏或没有被有效使用”。

- 使用已核验的预训练 H checkpoint（现有 probe 使用 2000-step 权重；实施时记录精确文件 hash，不擅自换 best）。
- H 和其 VGG teacher 冻结，预测描述符进入原零初始化 TC adapter；训练 adapter、UNet/RSI 及已有 local/R 模块。
- 不让 diffusion 梯度更新 H。H 的 L_comp 此阶段只作为监控，不把常数监控值当作能优化 H 的训练 loss。
- H 仍读取独立的 ref VGG 统计和目标 Ec，不依赖 Es、R、alpha 或 Delta。
- TC-off/on 两臂同时训练相同主干 2500 步；不只给 TC-on 额外训练步数，也不采用一个臂先冻结主干而另一臂不冻结的比较。
- TC adapter 零初始化并使用相同 global9 注入位置；第一轮不同时改变 teacher、输出分辨率或注入层。

这条路线成功后，TC 的完整训练流程为：GT 监督的补全预训练 → 冻结补全器的生成适配。没有必要要求所有模块端到端更新，才能成为完整方法。

若描述符仍预测准确但图像收益很弱，考虑空间 TC：目标 Ec 网格查询 ref VGG 局部证据，预测与目标 GT 对齐的 8×8 外观 teacher，再经零初始化空间投影注入 UNet。详细草案见后续选项附录的 P2；它不在本轮自动启动范围内，实施前需 review 并按实际特征形状复核。它是目标字补全能力升级，不是额外增加第四贡献。

## 5. P0：低成本判别实验与评测修复

先处理已确认的评测问题：推理 donor 使用与训练相同 clean-map，按 split 和预期文件清单检查完成情况，不能用总 PNG 数量判断 train/val 已完成。修复仅恢复协议正确性，不记作架构收益；全部比较臂统一修复。

固定 G2@10k、G2-RL@10k，固定采样器 DPM++、20 steps、CFG 7.5、每目标噪声。固定其他结构输入；置换 ref 时不能顺带换掉首 ref 关联的条件。

1. 同一集合置换顺序：排查非预期首 ref、padding 和截断依赖。
2. 整组重复：一张重复至 2/4/8；两张整组重复至 4/8。信息不增加，用于检查数量效应。G2 理论上应近似不变；G2-RL 可能受计数影响。
3. 四条预先固定的嵌套 ref 序列，比较 k=1/2/4/8；包含旧“永和书风骨韵天地”序列，其余按预定采样规则产生，不依据输出挑字。
4. 分离变化来源：固定 full-8 的 Delta 只改变 style refs；反向固定 style-8 只改变 Delta refs。此项标注为诊断，不作为真实 k-shot 主结果。
5. 记录 global/local attention 总质量、每 ref 质量、归一化熵 H/log(N_valid)，并观察分支输出范数。不要用随 token 数自然增长的原始熵直接证明“涣散”。

先用 val16 中预先固定的四个代表字体、每字体 12 个有效目标字做机制小面板，再将有效诊断扩到完整 val。12 字建议覆盖数字、大小写、带音标西文、假名和注音；不合法 font/char 按 clean-map 排除并报告真实分母。

四组参考组合是输入鲁棒性评测，不是训练四个 seeds。训练仍只保留一个 seed。

### 统一训练规格

- P1 的 G2/RL 各自从原 10k 父模型出发；不用不同训练历史的 CONT 与新臂混搭成严格对照。
- clean 数据、font/target/ref 抽样分布不变，沿用同一 1–8-shot episode 采样；global batch 64，seed 3407。
- 每个臂按 8 卡 DDP 顺序执行；不未经吞吐实测改成四组 2 卡任务。
- UNet/RSI/local 学习率 1e-5；P1 新 R 为 1e-4；P2 已训练 R 与主干同为 1e-5，新增 TC adapter 为 1e-4。Es/Ec/VGG 冻结。
- warmup 200 次真实 optimizer updates，之后固定 LR 至短实验结束；必须从实际 LR 日志验证，不能让 Accelerate 的多卡 scheduler 步进把 200 缩成 25。
- fp16 + GradScaler，clip global norm 1；新模块 softmax 等敏感归约使用 FP32。
- 先做 100-step 功能/资源试跑，正式配对臂重新从规定父权重和 seed 启动；试跑不混入各臂训练历史。
- 相同噪声/t/ref episode；固定 val 噪声和 t，分别记录 diffusion、perceptual、offset、梯度范数、AMP skipped updates、实际 LR、有效 k、mask、条件输出范数。训练 loss 不与不同定义的 val loss直接比较。
- 500/1000/2500 steps 导出固定小面板；首轮以相同步数比较，不用各臂不同步数的最优值混比。500/1000 的评测不强制保存完整 optimizer 副本。

核心四臂 + 两对 TC 共 20000 次 8 卡 updates；加 B2/B3 上限 25000 次。先用 100-step 吞吐估算工时，不承诺未经测量的完成小时数。后续空间 TC、D、R-mean 不含在此预算内。

服务器检查磁盘约 23–24GB 可用。执行前重新检查空间，依据真实 checkpoint 大小安排保存/归档。旧实验不自动删除；空间不足时先获得归档方案确认。旧 CONT 队列已完成；本轮采用新的独立队列，巡检更新为本轮范围。

## 7. 如何判断有效

### 效果与稳定性同时看

主 review 面板：相同字体、目标、ref、噪声、step 下并排 GT/基线/改动；重点看尖收笔、飞白、回卷、轮廓比例及特殊字形。所有选定字体都展示，不只展示成功案例。

量化：窗口 SSIM、L1、GT 边缘误差、前景面积误差，以及同 k 跨四组 ref 的质量方差与最差组合质量；分字体平均后再汇总，避免某字体有效字符较多而支配结果。新增自动风格评估器就绪后，用冻结版本统一补算，不等待它才做视觉排查。

- 改动应提高或保持 1-shot 质量，并改善 4/8-shot 的平均质量或低分位质量。
- 稳定性降低但全部变成普通字体，不算成功；输出彼此接近不是唯一目标。
- 不要求每一张生成图随 shot 严格单调，但需要总体趋势和较差参考组合都有改善证据。
- 在 val 上预先固定最终筛选规则，test 不参与选配方。核心测试仍沿用正式完整协议，另附 ref 组合鲁棒性子集。
- 若需数值门槛，建议把 1-shot 窗口 SSIM 相对退化不超过 1% 作为初始护栏，同时要求视觉不丢关键风格；该门槛待用户 review，不是已有结论，也不是仅凭此判定胜出。

## 8. 不同结果对应的下一步

| 结果 | 下一步 |
|---|---|
| R 在 G2/RL 都改善 | 保留共同接口；验证 TC；必要时做 R-mean 控制 |
| N 有效，R 无效 | G2 保持原接口，RL 保留 N；不强求两条主干使用同一改动 |
| R/N 稳定了 shot，但笔触仍弱 | 在胜出主干及其匹配对照上增加旧稿 D 的目标 GT 细节监督；不要只给 TC 臂加 D |
| 冻结 H 的 TC 恢复增益 | 固定“补全预训练 → 生成适配”流程，完成两主干 off/on 对照 |
| H 补全准确，TC 生成仍无收益 | 优先检查广播式接口的消费能力，升级空间 TC；不反复增大 H 的训练步数 |
| R 无效，且所需细节不在 Es 中 | 将高分辨局部证据放入 TC 的独立外观通路，不让 R 无限膨胀 |
| 连训练小集都无法拟合笔触 | 执行旧稿 128 对小集过拟合，检查分辨率、监督与生成容量，而非继续扩大 ref 数量 |

保留 TC 的研究位置，不意味着提前认定当前 TC 已有生成贡献。应通过上述最小修复和必要的空间接口升级，把目标字补全转化为真实的生成收益。

## 9. 论文组织与待确认事项

方法的叙事保持为：“从跨文字的少量参考中汇集风格证据，用结构变化先验约束目标字，再补全该目标字尚未被参考直接展示的外观。”R/N 是可靠读取证据的实现细节；Delta 与 TC 分别负责结构先验和目标外观补全。

固定查询的集合注意力已有 [Set Transformer](https://arxiv.org/abs/1810.00825) 等先例；目标 content 查询局部风格也已有 [FS-Font](https://arxiv.org/abs/2205.09965)。不把通用 attention 公式作为新贡献；TC 的重点是跨文字目标外观补全任务、监督接口和实证收益。

用户已批准：执行 P0 + P1a 四臂，为 P2 两对 TC 保留预算，B2/B3 由 P0/P1 结果触发。当前不改 Es、不改 Mean-Delta、不恢复 PRL 或 set-delta，不同时引入新 loss。
