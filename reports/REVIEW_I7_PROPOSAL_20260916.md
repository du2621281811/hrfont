## 1. "输出端约束"的定位（回应 PI 提问）

输出端约束（提案 Part D：变化区域 mask + 高频 + sqrt(ᾱ) 重加权）应加，但只是答案的一半，必须与"消费端"修复捆绑：

- **供给端（主症状）**：fit audit 实测 I5@4k 局部支路开/关对最终图像的影响仅 0.000506–0.000878 L1（像素范围 0–1，≈0.05%–0.09%），up-attention 内 ‖gain×local‖/‖old‖≈0.15%–0.24%。风格信息在条件里（换 ref 时 TC 读出与误差明显变化），但生成器基本没有消费它。
- **需求端**：I5 末批总 loss 0.04404 中输出细节项仅 0.000854；细节监督的时间加权在高噪声处天然弱（现为 ×alpha_bar，对 ε 梯度的有效权重 ∝ sqrt(ᾱ(1-ᾱ))），"必须改变的区域"上没有足够的梯度压力。
- **结论**：单独加输出端约束 = 重走 I3/I5 已试过的监督家庭（两轮结论：边缘级改善、不改变风格判断，4k 门失败过）。输出端监督只能制造"必须用条件"的梯度需求，不能创造条件里没有的信息；须与 B（归一化强制消费）同包。
- 判别器/分类器反馈（把 E12 类评分器当训练 loss）属此前已排除路线（E12-α 训评一体被否、不加 GAN），不建议重开。

## 2. 逐部分裁定

| 部分 | 提案内容 | 裁定 |
|---|---|---|
| **B 归一化强制消费 TC** | `A=(1-β)A_global+β·c_layer·A_TC`，β 前 1000 更新 0→0.8 后固定；不得自缩近零 | ✅ **有实测背书，是当前证据下最对症的一步**（audit §8.3 原话：比较原注入与"有明确非零强度的归一化局部注入"，不再允许自由标量把支路压到近零）。I2 的 local_gain=0.0495（I1 仅 0.0008、I5@4k 0.0006）说明通路可以被保持打开，不是结构性必塌。验收按 audit：关 TC 损失细节 / 换 ref 沿新 ref 改变 / 正确 ref 更贴 GT，三者同过；禁止在旧 checkpoint 上直接改 gain 当修复 |
| **C Delta 差分形变** | 去掉 zero-conv 门，`o=Offset(h,d)−Offset(h,0)`、`ΔDCN` 差分、rho→0.5 | ⚠️ **论证最弱、且 audit 明确反对本轮动**（§6：Delta 不是首要嫌疑，I0 无 Delta 仍保真不足；不应与采样升级同跑）。先读 I4/I5 checkpoint 的 `rsi_gain`（zero-conv \|w\| 均值，现成读数）：正常→不必做；塌陷→单独开臂。默认不进主臂 |
| **D 输出监督** | D_region+0.5·D_change+0.25·D_high；sqrt(ᾱ) 替换 alpha_bar | ✅ 保留为配套，但期望压住：audit §4 定性为"强假设、非已证明唯一根因"，且同类监督两轮（I3/I5）结论温和。sqrt(ᾱ) 属 audit 允许的"有界重加权"方向，但幅度不小：有效梯度权重在高噪声处放大约 1/sqrt(ᾱ)（t950≈23×）——必须先过 32 批 SNR 分桶梯度测量再冻结系数，保持可回退开关 |
| **A 采样/drop** | drop 0.10→0.02、source 0.25→0.05；60% 复杂配额；25% 配对 batch | ⚠️ 拆两半：drop 微调 + 配对 batch 便宜、保留（但与 D-P2「统一 source_drop=.25」字面冲突，且改变无条件分支质量 → 与 I4/I5 推理协议不再严格可比，需显式登记比较口径；配套 CFG 扫描同样）。**60% 配额按 audit §8.4 应做配对臂**（同配置同预算，当前曝光 vs 60%）；若只跑得起一臂，可打包但必须标注"采样归因缺失" |
| **E 验证** | E1 小数据可拟合性 gate → E2 主实验 → E3 clean 全协议 | ✅ E1 正是 audit §8.2 所需（每步随机 noise/t、drop=0、raw/EMA、错误 ref 须更差）；**作为硬闸门：E1 不过就停，不放大**。E2 改为三语种 + 复杂度分层面板（不再用 val192 代表全方案）是对 I5 最重要的一条修补。E3 统计使用 clean mask（audit §1：展示板混入 13/48/23 个被清洗排除的组合） |
