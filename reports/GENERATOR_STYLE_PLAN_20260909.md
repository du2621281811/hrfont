# 生成器风格改动方案 + E12 同分不变量（2026-09-09）

**今晚只保 F1；A1/A2 与 E12 预处理修复明天做。**

不打断 F1。新 F3b 仍等 F1 结束后按拓扑 own-font 开跑。本方案只动 **生成器的 style 条件**，不重渲画布、不重跑 F1/F2。

---

## A. 生成器：分三档，先测后训

目标：把倾斜、笔触对比、连/断、顿笔从「被 8×3×3 均值扔掉」改成「进得了 UNet」。F2 九个全局 token 保持不动，作为对照。

### A0 — 冻结（现在）

- F1 单独跑到 80k。
- 不改 96×96 A 协议、不改 Content 脸、不加像素 L1 当风格损失。
- 已排队：`f3b_topology_ownfont_s3407` = F2 + 拓扑 own-font support + 仍用 9 个全局 token。这一档 **只测 support，不指望救风格分辨率**。

### A1 — 只改推理，不训练（F1 跑着就能做）

固定 F2@75k 或 F3@80k，同一噪声，只改 style 聚合：

| 试验 | 做法 | 看什么 |
|---|---|---|
| k=8 mean（现状） | 8 ref 的 3×3 逐像素平均 | 基线：平、正 |
| k=2 / k=3 不平均 | 只喂最有特征的 2–3 张（如永+风，或人挑） | 立刻「有脾气」→ 平均是主因 |
| k=8 concat | 8×9 token 拼进同一条 style CA，**先不 mean** | 3×3 里若还残存单字笔触，CA 能选 |

交付：同一 16 测字体 × 探针字（`I/l/o/1`、带连笔的假名）面板。**有信号再开 A2 训练**；没信号说明 3×3 本身已经没了事件，必须上中层图。

### A2 — 训练改动（F1 完、F3b-S 开训之后再插，或与 F3b-S 并行短臂）

**共同规则：** 从同一 F0、seed 3407、80k 日程；新分支标准初始化；20k 看图再决定是否跑满。共享 RSI / Δ 不改。

**A2-geo（便宜，建议先做）**  
从 **StyleImage PNG 直接算** 几何标量，不经过 Es：

- 斜势：对 `I/l/1` 或全 style 字的 ink 二阶矩 / 骨架主方向  
- 字重：ink 像素率  
- 对比：骨架上的粗细 CV  
- 连断：孔洞数 + 交叉簇（可复用拓扑签名代码）

MLP 投成 **4 个 token**，拼在现有 9 个全局 token 后面。UNet 只多 4 个 context 位。斜势和连断这种「整副字体的全局几何」走这条，比等 3×3 自己长出来靠谱。

**A2-local（正对笔触/顿笔）**  
冻结 Es，从 **第三个 down block 的 256×12×12** 取特征（每格 ~8px，顿笔/接头刚够）：

- 每个 ref 自适应池化到 8×8 → 64 个空间 token  
- **禁止先沿 ref 平均再喂 CA**（规格旧写法会再洗一次）  
- 训练时对 8 个 ref 的 64 token 做 **ref 轴 attention 或等权后仍保留 64 格**；若显存不够：每 ref 池到 4×4（16 token），8 ref concat=128，再加 mask  

这是唯一对「这一笔怎么收」有分辨率的改动。对照必须是：

1. F2 control（现成，9 token）  
2. F3b-S（排队中，+support，9 token）  
3. F3b-S + A2-geo  
4. F3b-S + A2-local（或 geo+local）

2↔3 看全局斜势/字重；2↔4 看局部笔触。不要把 geo/local 接到 F1/F2 共用通路。

**A2 明确不做**

- 像素 L1 / MSE 当风格损失（会把近像素、异风格拉近）  
- 改画布比例  
- 跨字体 Ec 再均值  
- 在 F1 没跑完时开第二张大卡抢 I/O  

### A3 — 以后（有 A1 信号且 A2-local 仍不够）

显式骨架条件（方向图/端点图）进独立 cross-attn；或拉丁 ref（斜体/连笔必须在 style 集里）。那是换数据协议，另开 dataset ID。

## B. E12：L1 一样、肉眼一样、分不一样 —— 不合理，当 bug

**不变量（应写成测试）：**

> 同一套 ref8、同一预处理、模型 `eval()`。若两张 query 的输入张量 L1=0（逐像素相同），则 `mem_logit` / `mem_prob` / `phi_sc_r` 必须在 1e-5 内一致。

肉眼一样且 PNG 上 L1≈0 仍分差大，不是「风格灵敏」，是 **度量不稳**。可能原因（按我们仓库里已有的坑）：

1. **打分脚本对已是 96×96 的图仍做 BILINEAR resize**（`score_f03_e12_v51.py` 的 `load_rgb01`），训练 dataset **不 resize**。同图两条路径张量可以不同；两张「看起来一样」的 PNG 若一进 resize 一不进，分会跳。  
2. 比的不是同一条件：membership 是 `s(P|R)`，R 是 **该字体的 ref8**。换字体、换 GT vs pred 的 ref，分本来就该变。必须同 font、同 ref 张量。  
3. RGB vs L、`convert("L")`、pred 存成 RGB 抗锯齿 vs GT 调色板，L1 若在不同颜色空间算，会「L1 很小但张量不同」。  
4. 半像素平移 / 1 级灰度：ResNet+GAP 可以对 1px 抖动给出很大 cosine 差。这是 Lipschitz 坏，不是风格。

**L1 的正确用法（仍不是训练目标）**

| 该做 | 不该做 |
|---|---|
| 不变量测试：L1(query_a,query_b)=0 ⇒ 分数相等 | 用 L1 当 membership 损失 |
| 近复制探针：L1 < 1/255 时，分差应 < ε（预注册 ε，如 logit 0.05） | 用 L1 小判定「风格相同」 |
| 修预处理：已 96 则禁止 resize，hash 真正进网的 tensor | 把 E12 改成像素重建 |

若近复制探针失败：先修 `load_rgb01` 与训练一致，再对 embedding 做输入噪声 Lipschitz（小 σ 高斯，分差上限）。这是校准/稳健，不是让 E12 去学顿笔。

顿笔/连断仍按 A 节给 **生成器**；E12 主任务继续是家族成员。E12 只保证：同样的图同样的分。
