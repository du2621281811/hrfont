# I7提案：以目标字体保真度为中心的条件学习

状态：2026-09-16，供PI review；未实现、未派发，不改变I5暂停状态。I7是建议编号，I6仍保留给原中文辅助方案。本轮优先中→西文/假名/注音主任务，不新增中文分支或新评测网络。

## 目标与不变项

目标：生成图在笔端、断笔、空心、装饰及局部连接等方面接近真实GT；正确ref/TC与有效Delta带来有益的响应，而非仅产生更大扰动。

保持三项主叙事：跨文字字体补全任务与评测；Delta表示潜在结构变化候选空间；TC从参考集合补全目标字外观。采样/drop/loss是训练配方，不包装成额外贡献。

数据使用0913清洗后有效font–char对，原生96、白底黑字与现有渲染/前后处理不变。正式评测过滤clean pair并保留旧展示板协议。content始终提供字符身份和基础结构，不整体删除、不奖励生成图无条件远离content。

原独立drop下Delta有效概率约0.9×0.75=67.5%；新值约0.98×0.95=93.1%。TC/ref有效概率约90%→98%。联合drop仍同步处理content、ref、TC和Delta，保证训推无条件定义一致。

删除与60%配额冲突的旧3倍基础概率cap；复杂池内先均匀选字体，再选字符，限制单字体垄断。每个成功更新记录实际比例，不只保存配置值。前500更新从30%复杂配额升到60%。40%其余数据包含未确认复杂的字体，不把未审字体一律称为简单字体。

现有22个确认组可用于小样本验证，但全量正式方案应扩大审核覆盖；如果来不及扩大，明确称为“22组高重复曝光试验”，不能据此声称复杂字体总体泛化。复杂组中兼顾具有可见装饰的目标字与普通字符，不只训练U/一类不易表现风格的字符，也不把简单字完全删掉。

每批约25%的样本按“同一目标字符、不同字体”成对安排，使用各自正确中文refs和GT，兼容60/40配额与clean约束。不加错误目标，不新增模型前向次数。这样同一个content对应多个真实外观，配合高噪声监督减少只用content的捷径；成对batch本身不是数学上足够的防捷径保证。

## B. TC/ref：从微弱残差变为主要风格入口

保留现有在线多尺度Reader、144个目标对齐tokens和InkReadout；不另加TC模块。只替换up-block的消费接口。

旧接口：`A = A_global + free_gain × A_TC`，free_gain可缩到近0。

新接口：`A = (1-beta) A_global + beta × c_layer × A_TC`。

- beta为固定训练日程，前1000成功更新0→0.8，之后固定0.8；不是自由可学习的近零门。
- c_layer使用少量训练批次的RMS做一次稳健幅度校准并冻结，防止随机投影尺度差导致突然放大。标量初值不是效果保证，验收仍测真实输出影响。
- down路径原全局ref先保留；上采样风格主入口逐步交给TC，避免同时大改所有路径。
- TC读出监督仍直接接实际送入生成器的tokens，Reader/out投影正常反传，原Es/Ec缓存语义不热改。
- 从共同I0初始化做新run。不能直接把I5旧检查点的gain改为1后，将强扰动当作修复。

验收要同时满足：关掉TC会损失目标细节；换ref会沿新ref的字体外观改变结果；正确ref使生成更接近正确GT。单纯像素差大不算成功。

## C. Delta：保持候选空间，去掉容易失效的消费门

不改donor库、own-font排除、alpha筛选或现有动态set权重网络。Delta仍为候选结构变化的加权组合，不当作目标字体风格本身。

当前结构残差经过zero-conv，可能与小offset一起弱化为接近无作用。建议把已有结构消费接口改为差分形变：

```
d = sum_j w_j Delta_j
o = Offset(h,d) - Offset(h,0)
h_new = h + rho × [DCN(h,o) - DCN(h,0)]
```

- 复用同一Offset网络与同一DCN权重，无新增结构预测网络。
- rho前1000步0→0.5，之后固定0.5；移除该位置可将整条结构贡献置零的zero-conv门。
- d=0时严格回到h，避免把DCN自身的卷积效果误当Delta贡献。
- 实际offset幅度正则系数从0.25改为0.05，保留平滑与稳定约束；CFG/source drop时严格关闭整个差分残差。
- 两次Offset/DCN调用增加算量，需短测吞吐；不预先声称无额外成本。

这里不硬规定“每个字都必须因Delta大幅变形”。候选无帮助时，弱响应合理。要求是在确有结构差异且候选有覆盖的样本上，正确Delta比关闭/打乱更接近GT粗结构。用输出误差监督真实收益，不用最大化offset或图像差异来制造贡献。

## D. GT导向监督：突出content需要改变的位置

设C为该目标字的实际中性content图，Y为GT，X为预测图。所有mask只从训练GT/content计算并detach，推理不需要GT。

1. 保留I5区域均衡距离D_region，覆盖墨迹、内部/近邻白区及背景。
2. 增加差异区域：`M = dilate(|Y-C| > 0.10, kernel=3)`，用M内平均|X-Y|作为D_change；mask为空跳过。它会同时约束该加的笔触和该删除的content墨迹。
3. 增加两尺度局部高频距离D_high：对X/Y的固定高通（图像减去3×3均值滤波）作L1，96/48尺度；在GT/content墨迹并集的邻域归一，强调断笔、笔端与描边，不在整张白底上稀释。区域阈值/算子在训练集短检后冻结。

提案初值：`D_out = D_region + 0.5 D_change + 0.25 D_high`；TC读出用`D_region + 0.5 D_change`。

不要把`|(X-C)-(Y-C)|`当成新目标，它与`|X-Y|`相同。实际新增的是差异区域的权重与高频细节约束；也不使用`-D(X,C)`，以免奖励不正确的远离content。

针对高噪声监督弱的问题，把输出细节时间权重从alpha_bar改为sqrt(alpha_bar)，在未裁剪的x0_hat上用有界梯度的L1/Charbonnier距离。对epsilon预测，sqrt(alpha_bar)与x0反推的1/sqrt(alpha_bar)相抵，避免简单取消权重造成高噪声梯度爆增，同时不再像原alpha_bar那样压低高噪声梯度。主epsilon目标与时间采样保持不变。

总损失初值：

`L = L_eps + 0.01 L_VGG + ramp × [0.02 D_TC + 0.05 sqrt(alpha_bar) D_out] + 0.05 L_offset`

GT相关附加loss只作用于有效条件样本，固定batch分母；前1000更新ramp。保留原VGG为辅助，不以其下降证明风格提升。32个训练批次按SNR分桶检查梯度、溢出、裁剪比例，再冻结细节系数；不得根据test调参。sqrt权重的有界性针对这里的L1/有界导数距离，不泛化到任意二次感知损失。

## E. 验证与执行顺序

### E1. 小数据可拟合性：先做，不扩成长期诊断

- 例如8字体×4目标字，覆盖三语种和多个细节类型；都是真正clean训练pair，中文refs固定且正确。
- 8卡，global32；最多1000成功更新，drop=0，noise/t每步更新。200/500/1000步从纯噪声生成，不把单次带噪GT重建当生成结果。
- 比较raw与EMA，固定若干采样seed，观察结构、笔触和风格；这不是论文多seed训练实验。
- 相对同数据I0，目标为复杂区域误差中位数降低至少20%、至少24/32样本改善，且清楚复现预先标记的笔端/断笔/空心等细节。它是建议工程放行线，不是保证一定达到的效果。
- 同时要求正确ref/TC优于错配；有用结构子集上正常Delta优于关闭。改善需与GT一致，不能只要求干预有像素差。若未达标，先定位接口/监督，不继续10k大全集。

### E2. 主实验I7：先追求效果

- 从共同I0独立初始化，不从I5@4k续训，避免旧抑制状态与新方法混在一起。小数据预检权重丢弃，不带入正式run。
- 8张V100，global64；最多10k成功更新；继承UNet LR2e-5，Reader/router新模块LR1e-4；500步LR warmup、5k后cosine至10%；FP16+GradScaler、clip1、EMA沿用。
- 2k/4k看三语种和复杂度分层的完整生成图，不再用仅四个西文字的val192代表全方案；10k做clean matched全协议。
- 先主实验，看到实际收益后再补“只改采样/drop”和“去TC/去Delta”等同预算单变量消融，不把不同训练步数直接当贡献比较。
- 不引入中文辅助、E12训练反馈、矢量decoder或新Es预训练；这轮把变化集中在采样、条件消费与监督。

### E3. 主评估

1. GT保真：区域/高频/差异区域误差、整体L1/SSIM以及标记细节视觉检查。
2. 相对中性content的进步：`P = 1 - D(X,Y)/(D(C,Y)+epsilon)`；只统计C与Y差异足够大的样本，P=0相当于复制content，P=1为GT。不要把这个诊断当新通用风格指标。
3. 完整条件响应：真实ref交换、TC关闭、Delta关闭/打乱；分别固定其他输入作为诊断，再用一致条件重算完整管线。扰动本身不是质量收益，零/打乱条件也不是训练消融的替代。
4. Delta分两层判断：推理干预检验是否被使用；同预算无Delta训练对照才能检验其不可替代的贡献。没有帮助的候选不强制响应。
5. E12c仅作辅助相容性统计，当前不做训练loss或主放行标准；所有展示与统计使用明确clean mask。

以上为提案参数，不是已实测最优值。采用ml-training-recipes中的过拟合与训推一致性检查，将放行标准从数值健康改为完整生成与正确条件利用。
