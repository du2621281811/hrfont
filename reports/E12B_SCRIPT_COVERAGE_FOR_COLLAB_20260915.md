## A. 数据怎么用（先看这个）

E12-b **不生成字形**，只学「风格打分」。数据分四步：

```
① 筛字体/字符（v0913_clean）
② 建成 cache PNG（训练用）
③ 用 cache 训 φ，再冻 φ 训 membership
④ 打分：读 test 的 StyleImage + 生成图（不读 cache）
```

| 步骤 | 用什么数据 | 干什么 |
|------|------------|--------|
| ① 筛 | train 字体 + `fonts.tsv` bucket + `pairs_train` | 踢掉 exclude；某字体某语种不可用则该 (font,char) 不进 |
| ② cache | 协议 A 的 Style/Target PNG → `artifacts/e12/cache_v0913_b/` | 约 **223 字体 · 7.9 万张**；**只服务训练** |
| ③a 训 φ | cache：**同字体** 1 中文（104 种之一）+ 1 拉丁（52 种之一）；字体 holdout train≈156 | 学跨语种风格向量 |
| ③b 训 membership | cache：**query 62（字母+数字）** + **ref 8 汉字**；同/异族；冻 φ | 学「像不像本族」 |
| ④ 打分 | **不读 cache**；目标字体 **ref8 StyleImage** + GT/生成西文图 | φ→余弦；membership→概率；`keep=0` 丢掉 |

**刻意不用的：**

- 数据集 **val16 / test16 字体**：不进 ①②③（只在 ④ 打分）
- **生成图**：不进训练
- **假名 / 注音**：可进 cache；**不当 membership 主监督**；报分仅诊断子集

**两个分数：**

| 名字 | 怎么算 | 主/辅 |
|------|--------|-------|
| Ours φ | 生成图过 φ，与 ref8 中文原型比余弦 | **主** |
| mem 概率 | 生成图 + 同字体 ref8 → membership | **辅**（主表看 latin+digit） |

## B. 语种范围（内部）

### B1. 字体 bucket

训练只用 **train 223**（228 − 5 exclude）。

| bucket | 字体数(train) | 允许的语种（训练条目 + 打分 keep） |
|--------|---------------|-----------------------------------|
| `all_scripts` | 130 | 汉 + 拉丁 + 数字 + 假名 + 注音 |
| `no_bopomofo` | 58 | 上列 **无注音** |
| `han_latin_digit` | 35 | **仅** 汉 + 拉丁(含扩展) + 数字 |
| `exclude` | 5 | 全扔 |

### B2. 各语种在 cache 里有多少

| 语种 | 字符种数 | PNG 条数 |
|------|----------|----------|
| 汉字 | 102 | 22,746 |
| 数字 | 10 | 2,230 |
| 拉丁大写 / 小写 / 扩展 | 26 / 26 / 27 | 5,798 / 5,798 / 6,021 |
| 平假名 / 片假名 | 83 / 86 | 15,604 / 16,168 |
| 注音 | 37 | 4,810 |
| **合计** | — | **79,175** |

### B3. 每一次训练各自吃的数据范围（精确）

字体先在 223 内按族 **70/15/15**（seed 3407）划分 ≈ **train 156 / val 33 / test 34**（选模用；≠ 数据集 val16/test16）。

#### ① 训 φ（`e12_phi_s2_b_s3407`）

| 项 | 范围 |
|----|------|
| 字体 | 上表 train **156** 族（正样本）；负样本可从 train∪val 抽异族 |
| **中文** | **104** 字：`永和书风骨韵天地` + `一二三…江海河湖原`（见 config `chinese_chars`） |
| **拉丁** | **52** 字：`A–Z` + `a–z`（**无数字、无扩展拉丁、无假名注音**） |
| 一条训练样本 | 同字体一对图：**1 中文 + 1 拉丁** |
| 样本索引规模 | 约 **156×(该字体有的中文)** ≈ **4836** 个 (font,中文) 键；拉丁按 index 轮换 |
| 训练量 | max **5000** steps，batch **64**，InfoNCE |
| **不用** | 数字 / 拉丁扩展 / 假名 / 注音（不当 φ 主对比字符） |

#### ② 训 membership（`e12_membership_b_s3407`）

| 项 | 范围 |
|----|------|
| 字体 | 同上 holdout 的 train **156**（episode 内同族/异族） |
| **query** | **62** 字：`A–Z` + `a–z` + `0–9`（**仅字母+数字**） |
| **ref** | **8** 汉字：`永和书风骨韵天地`（固定 ref8） |
| 一条 episode | 1 张 query 图 + 8 张 ref 图；偶数同族 / 奇数异族 |
| 训练量 | **20000** episodes，batch **32**；冻住 φ |
| **不用** | 假名 / 注音 / 扩展拉丁 / 其余汉字（不当 membership 主门） |

#### ③ 打分（非训练，列在这里对照）

| 项 | 范围 |
|----|------|
| ref | 目标字体 StyleImage **ref8**（同上 8 汉字） |
| query | GT 或生成图；主表 **latin+digit**，且 `keep=1` |
| 字体 | 应用集（如 test16），**不是**上面 156 |

### B4. 报分默认看什么

- **主表**：latin + digit，且字体 bucket 允许该语种（`keep=1`）
- 假名 / 注音：仅诊断；注音还要求 `all_scripts`

---

## C. 一句话

> **φ：156 族 × 104 中文 ↔ 52 拉丁。**  
> **membership：同 156 族 × query62(字母数字) + ref8 汉字；假名注音不进主门。**  
> 打分另用 test Style/生成图，主看 latin+digit + keep。
