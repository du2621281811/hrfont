# E12-c：独立人评与统计协议

版本：E12C-LITE-DRAFT-20260915。供review，尚未采集。配套[模型与训练设计](E12C_PLAN_20260915.md)、[交接入口](E12C_HANDOFF_20260915.md)。本版人评只评价冻结模型，不参与训练、选checkpoint或调参。

## 1. 评价问题

主问题Q1：自动分数能否反映跨文字风格相容性？次问题Q2：能否反映整体补全合理性？同一批评分也用于I0/I1/I2生成质量比较。相关性按逐图数据计算，不用三个方法的三个均值计算相关系数。

## 2. 样本与工作量

- 正式288图：16个主任务test字体×每字体6个有效目标字符×I0/I1/I2。96个字体—字符条件均衡分配1/4/8-shot，每档32个条件；每个条件的三个方法共享生成参考和seed。
- 建议从16个不同谱系各取一个字体实例，使字体cluster与谱系cluster一致。若合格test谱系不足16，先review调整样本规模；若确需每谱系多个实例，则改按谱系bootstrap并报告实际cluster数，不把近亲字体当作独立cluster。
- checkpoint在看人评前锁定，默认各方法正式10k版本；I0的复用权重身份单独记录，不误写为新训练。不存在的匹配结果须补推理，不能补造记录。
- 主任务val只供独立试问卷；已有I系列4096张val结果不能重新标成test。已有推理只有在split、字符、ref、seed及checkpoint均满足清单时才复用。
- 从清洗映射中的合法Latin/假名/注音取样，覆盖主要字体风格类别。各字体脚本配额按实际合法字符确定，缺失与替补规则在人评及自动分数产生前锁定，不按生成观感挑样。
- 每图3个独立标注者，共864次双问题判断。可由更多人分担，但每图保持3份有效评分；标注者需能判断分配的目标脚本。不熟悉就选“无法判断”，补派给合格者，不填中间分。
- 先用24–36张独立pilot图检查题意与流程，不纳入正式统计、不用于选择指标。正式样本清单、评分说明、QC规则在pilot后锁定。

这只是初始预算，并不保证统计显著。864次×15–20秒约3.6–4.8人时；培训、QC、补标和组织周转另计。

## 3. 标注界面与问题

上方展示固定中文参考“永和书风骨韵天地”，下方展示一张生成图和目标字符文本。显示96px原图与统一倍率放大，不做锐化等增强。不给目标字体GT，不显示方法、shot、checkpoint、字体文件名或自动分数。随机顺序，尽量隔开同条件不同方法，不要求强制A/B排序。

### Q1：风格相容性（主维度）

> 从笔画粗细、端点、曲直、书写感和装饰特征看，这个生成字与上方中文参考是否具有一致的字体风格？不同文字不要求具有相同的笔画结构。

| 分数 | 含义 |
|---|---|
| 1 | 明显不相容 |
| 2 | 相容程度较低 |
| 3 | 部分相容，但存在明显差异 |
| 4 | 比较相容，仅有少量差异 |
| 5 | 很相容，看起来属于同一套字体设计 |

### Q2：整体补全合理性（次维度）

> 综合目标字符是否正确、字形是否完整，以及与参考的风格协调程度，这个结果作为该字体的补全是否合理？

| 分数 | 含义 |
|---|---|
| 1 | 明显不合理，有严重错误 |
| 2 | 合理程度较低，问题较多 |
| 3 | 部分合理，但有明显问题 |
| 4 | 比较合理，仅有少量问题 |
| 5 | 很合理，完整且协调 |

每个维度另有“不熟悉/无法判断”，不计为3分。装饰不自动等于伪影；评价设计一致性，不评价个人是否喜欢该风格，也不要求复现未展示的GT。字符难以辨认可以导致Q2低分，Q1仍应按是否能判断风格独立作答。

## 4. 质量控制

正式前提供短说明与练习。少量重复题只用于一致性检查，标为QC，不重复计入独立样本。检查题由熟悉脚本的人确认，例如明显错误的目标字符；不把“异字体”自动设为差评，也不把GT一律设为满分。

异常速度、重复题冲突、检查题失败触发复核。具体阈值、排除和补标规则在pilot后、正式前锁定；不得按评分是否支持本方法来剔除。保留匿名原始记录、排除原因和清洗日志，报告评分者一致性及分歧。

目标是每图Q1和Q2各有3份有效评分，按维度记录有效数。未能补齐时报告实际覆盖；各指标相关性比较使用同一有效样本交集，不能分别筛选有利子集。

## 5. 统计方法

1. 每图分别求有效Q1、Q2的均值。主自动指标为E12-c完整头logit；主关联为与Q1的Spearman，Q2为次关联，同时报告两个维度的Kendall tau-b。
2. 并列分使用average ranks，Kendall使用tau-b。常量输入或不足样本返回NA及原因，不置零。统计样本数是288张图，不是864份评分；同时报告字体数和各维度有效数。
3. 同一字体—字符—shot条件内，将三个方法的人评均值组成两两顺序，计算自动分数与其方向一致率。人评完全并列的对不进入分母，单独报告并列比例；人评不并列而机器并列计0.5。该量叫“组内顺序一致率”，不是直接A/B偏好准确率。
4. 按字体cluster bootstrap 2000次、固定seed，重采样时保留字体内全部字符/shot/方法及评分对应关系，计算95%区间；比较两种指标时使用同一重采样得到差值区间。16个字体cluster可能产生较宽区间，如实报告。
5. 首先报告相关系数和区间。若补充p值，应采用考虑字体聚类的方法，不直接把所有图当独立样本使用渐近检验。脚本/shot分层附实际n；生成方法的人评分先字体内平均，再跨字体宏平均。
6. 不根据正式结果更换主指标、翻转分数方向、挑样或追加到“显著”为止。旧E12-b的39张/单人评测回答的问题与本协议不同，不混合成同一正式统计。

固定8张评测ref只统一评判证据，不改变生成时的1/4/8-shot条件。故本协议同时检验不同生成shot，但不声称评测器本身只看相应shot。
