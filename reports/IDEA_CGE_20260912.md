## 1. 定位与前向路径的边界

一句话：**Δ 定义证据空间（前向，一次生成内）；CGE 导航证据空间（优化，多次生成间）；E12 提供导航信号。**

与 Δ 的贡献边界：

| | Δ / RSI 贡献（已确定） | CGE（本 idea） |
|---|---|---|
| 路径 | 前向：证据 → RSI → 结构 | 反向：评测反馈 → 证据配置更新 |
| 作用域 | 单次生成内部 | 跨多次生成 |
| 操作对象 | 残差的消费方式 | **输入侧的证据配置**（donor 子集/权重） |
| 共享通道 | — | 不碰生成器、不碰 RSI |

CGE 不重蹈「字符感知检索」的归因陷阱——检索改造仍走前向 RSI 路径，会被读成 Δ 的同一贡献；CGE 是一个独立的优化阶段 + 新任务。

## 2. 实现路径（四阶段，每步有判据）

### Phase 0 — 可行性探针（1 天，零训练，生死关）

- 做法：离线采样 K 个证据配置（沿属性方向换 donor 子集/权重）→ 现有 F3b-P/F2-P checkpoint 生成 → E12 配对打分。
- 判据：**E12 排序是否与属性方向单调相关**（换粗 donor → 字重方向子分上升）。
- 预警依据：F2 系 s1≈s8、F2≈F3 说明证据变化可能推不动输出（脏数据期）；F3 的 shot 敏感性说明检索在 F3 系是活的。探针是裁判。
- 放弃条件：单调性不成立 → 整体 idea 放弃，不进入 Phase 1。

### Phase 1 — 学习编辑轴（1-2 天）

冻结 Ec/Es 特征上训线性探针，得「字重/斜势/衬线」属性方向。每个证据配置 = donor 集的属性投影 → 低维坐标（4-8 维）。证据空间从离散集合变成有结构空间。

### Phase 2 — 学习导航代理（1-2 天）

轻量 MLP：输入 (证据配置坐标 + refs 嵌入 + 目标字符嵌入) → 预测 E12 φ_s2 或配对胜率。训练数据 = Phase 0/1 的采样-生成-打分对（几千条；96px 生成 ~1-2s/张，总成本小时级）。

### Phase 3 — 推理期优化

默认 α 配置起步 → 代理打分 → 低维坐标梯度/坐标搜索 → 选改善配置 → 生成最终候选（1-2 次生成，对比朴素搜索 K 次）。代理只提议；最终产物用真 E12 验一次；判定交人评。

## 3. 为什么够一个完整贡献

- 可学习组件 ×2（编辑轴 + 导航代理），优化是真实搜索不是 batch 采样
- 新任务：证据空间的 test-time optimization。类比：LLM reward-model 引导搜索、StyleCLIP 系 CLIP 引导潜空间编辑；**字体生成里无人做评测器引导的证据空间优化**
- E12 从指标升格为机制：评测进入生成环路（评估-生成闭环），把「1.5 中的 0.5」与新增量焊在一起
- 不抢 Δ 主位：Δ 是空间定义者，CGE 是空间导航者

## 4. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 证据空间推不动输出（脏数据下 donor 换不出可见差异） | **致命** | Phase 0 探针 gate；阴性整体放弃 |
| Goodhart（代理过拟合评测器偏差） | 高 | 配对训练（相对判断）+ 真 E12 终验 + 人评终审 |
| E12 T2 门未过（0.9009 压线） | 高 | 探针即 E12 有效性检验；机制 downstream-gate 在 E12 |
| 编辑轴解释性弱（线性方向老旧套路） | 中 | 不声称可解释性；定位 = 属性条件检索（InterFaceGAN 血统），仅作 CGE 的空间结构工具 |
