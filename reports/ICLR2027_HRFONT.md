## 1. 一页纸

**任务：** 用一套中文字体的少量汉字当风格，生成同一套字体里的拉丁 / 标点。内容图是中性字体上的目标字；真值只用于监督和打分。

**主张：** 跨语系 few-shot 失败，是因为参考字盖不住目标字的结构。参考是「十」、要写 `a` 时，模型看不到圈，也不能用汉字轮廓去扭拉丁。

**做法：**

1. 用中文参考在训练可见字体池上估 α（像哪几套库字体）。  
2. 把 α 加到库字体里**同一个目标字**上，得到 Δ：这个 `a` 该往哪变。  
3. 再检索**完整字** \(q\)（不是偏旁切片）：\(q\) 身上带着 \(c\) 该学、而参考里没有的结构知识（`a` 要学封闭字腔 → 整字 `口`/`o`）。从高 α 库取出整字图。用户汉字仍是唯一真风格。

风格源永远是中文 few-shot，不是该字体里已有的拉丁。同一套管线也跑中文→中文。

官方 FontDiffuser 是开源扩散骨干，也是表里的跨语失败基线：合作者已用官方权重建模中→西，**整体风格就不像**目标中文家族。主证据是写对、LPIPS、按拓扑缺口分层、设计师二选一。

## 2. 主张（投稿只锁这三条）

1. 跨语系 few-shot 字体生成的病态，主要来自**参考字盖不住目标字的结构**（拓扑缺口）。  
2. 中文估 α + 同字 Δ，可以在**不把汉字轮廓当形变场**的前提下，得到能单独用的生成器。  
3. 检索带着「\(c\) 该学而参考没有的知识」的**完整字**；增益随缺口增大而增大。

不要写成「CF-Font 模块接到 FontDiffuser 上」。

## 4. 方法

### 4.1 估 α（只用中文）

参考汉字 \(r_1\ldots r_m\)（锁 `永和书风骨韵天地`，\(m=8\)）。候选库 \(B_1\ldots B_S\) 是训练集上的字体（不含 Demo-8）。

\[
W_{k,s}=\cos\big(E_s(R_k),\,E_s(I(B_s,r_k))\big),\quad
\alpha=\mathrm{softmax}\Big(\tfrac{1}{\tau_\alpha m}\sum_k W_{k,:}\Big)
\]

\(E_s\) 用官方 FontDiffuser **style encoder，冻结**。多字是为了让 α 稳。取 top-\(M\) 再归一化，用来混 Δ。

规格见 **4.5.1**。

### 4.2 同字变化 Δ

只对 α 最大的 \(M\) 套：

\[
\Delta = E_c\!\big(\textstyle\sum_s\tilde\alpha_s I(B_s,c)\big) - E_c(I(B_0,c))
\]

相对中性 `a`，在「像目标风格的库」里 `a` 该怎么改。像素混合只可视化，进网络用特征差。

### 4.3 支撑字（完整字，不是偏旁）

「十」盖不住 `a` 的圈。用来检索的 \(q\) **不必等于** \(c\)，但必须是**一张完整字形**，不是裁出来的部首、笔画或局部 mask。模型要从整字里读「这块知识在目标风格里长什么样」，而不是拼偏旁。

**选谁：** 不要按「整字像不像 \(c\)」。整字 cosine 会挑到轮廓接近的 `n`、`u`，却漏掉真正该学的封闭字腔。应按 **参考还解释不了的知识方向** 来选完整字：

\[
v_x=E_c(I(B_0,x)),\quad
v^{\mathrm{miss}}_c=v_c-P_{R}\,v_c,\quad
\mathrm{cover}(q)=\cos(v^{\mathrm{miss}}_c,\,v_q)
\]

\(P_R\) 是参考整字特征张成子空间上的投影。`cover(q)` 高 = 完整字 \(q\) 带着 \(c\) 该学、参考没有的方向。再从高 α 库取**整字图** \(I(B_s,q)\)。**\(q\neq c\) 禁止并进身份支路。** 进网络前减掉中性整字特征，只留风格差。

拓扑缺口（测试可算，不用 GT）：

\[
\mathrm{gap}(c,R)=\|v^{\mathrm{miss}}_c\|_2/\|v_c\|_2
\]

gap 大则打开支撑。**主图：横轴 gap，纵轴（开支撑 − 关支撑）。**

规格见 **4.5.2**。

### 4.4 四条条件流

| 流 | 输入 | 作用 |
|----|------|------|
| Style | 只吃用户汉字 \(R\) | 真风格 |
| Identity | 中性 \(I(B_0,c)\) | 这是哪个字 |
| Change | Δ | 往哪变 |
| Support | 完整支撑字；gap 低时为空 | 把该学的结构知识送进 UNet |

### 4.5 检索规格（请 review；下列数字是默认提案，未在 Demo-8 上扫过）

不新训检索网。风格近邻用冻结 \(E_s\)，结构近邻用冻结 \(E_c\)。两个都是官方 Phase 1 的 FontDiffuser encoder。\(B_0\) 用一套同时含拉丁和汉字的中性字体（Noto Sans CJK / 项目现用 source），所有 \(c,q,r\) 都在 **同一套 \(B_0\)** 上编码，避免「拉丁 DejaVu vs 汉字宋体」把字体差写进结构分。

#### 4.5.1 选 α 近邻字库

**池，不是再聚 8～12 套。** CF-Font 把 basis 收到 ~10，是因为他们要在小基底上插值内容。我们只要 top-\(M\) 近邻混 Δ，42 套 × 8 个参考的 \(E_s\) 一次算完可缓存。

| 项 | 默认 | 说明 |
|----|------|------|
| 候选池 \(\mathcal{P}\) | 训练 42 套，不含 Demo-8 | 训练时 leave-one-out：当前 \(f\notin\mathcal{P}\) |
| 字体原型 | \(e_s=\frac1m\sum_k E_s(I(B_s,r_k))\)，\(r=\)`永和书风骨韵天地` | 测试时用户 \(R\) 与各 \(e_s\) 比；训练时用该字体同一 8 字 |
| 相似度 | 逐字 cosine 再平均，再 softmax | 即 4.1 的 \(W\) |
| \(\tau_\alpha\) | **0.07** | 与对比学习常用温度一致；偏尖则只信最近邻，偏钝则混得散 |
| \(M\) | **3** | 混进 Δ 的套数；top-3 重新归一化 |
| 是否设 α 下限 | **否** | 永远用 top-3，不因「不够像」拒识 |

**变体（实验里比一次，不当第二套方法）：** 先在 \(\{e_s\}\) 上 K-Means，\(K=12\)，每簇取 medoid，再只在这 12 套上算 α。这是 CF-Font 式 spanning basis。默认仍是 42 套 kNN。

**实现：** 离线渲 \(\mathcal{P}\times\{8\text{ 参考}\times\text{P1 全表}\}\)；缓存 \(E_s\)、\(E_c\)。推理只做 8×42 次 style cosine + top-3 读图。

#### 4.5.2 选带着 \(c\) 该学知识的完整字

排序键是 **残差覆盖** `cover(q)`，不是整字 `sim(c,q)`。消融里用整字 kNN 当对照，证明「轮廓像 \(c\)」≠「带着该学的知识」。

取 \(K\) 个时用 MMR，避免 3 个完整字都挤在同一知识方向（三张都是字腔、没有字干）：

\[
q_{t+1}=\arg\max_{q\notin\{c\}\cup Q_t}\Big[\lambda\,\mathrm{cover}(q)-(1-\lambda)\max_{q'\in Q_t}\cos(v_q,v_{q'})\Big]
\]

| 项 | 默认 | 说明 |
|----|------|------|
| 结构编码器 | 冻结 \(E_c\)，最后一层 **spatial mean-pool** 再 L2 归一 | 与 Δ 同一套；残差在这个向量空间里算 |
| 候选集 \(\mathcal{Q}\) | P1 的 `A–Z a–z 0–9`（62）+ 下面 18 个中文供形字 | 标点先不进检索（拓扑太碎，单独靠 Δ） |
| 每字取 \(K\) | **3** | \(q\neq c\)；不足 3 个过阈就少取，不补随机字 |
| 覆盖阈值 \(\theta\) | **0.25** | `cover(q)<θ` 丢掉（残差余弦，尺度小于整字 cosine） |
| 打开支撑的缺口 \(\gamma\) | **0.35** | \(\mathrm{gap}(c,R)\ge\gamma\) 才喂 Support；否则空 |
| MMR \(\lambda\) | **0.7** | 1=只追覆盖；0=只追互异。0.7 偏覆盖、仍拆开不同知识方向 |
| 库侧 | 只从 α 的 top-\(M\) 套取 \(I(B_s,q)\) | 权重 \(W^{\mathrm{sup}}_{q,s}=\tilde\alpha_s\cdot\mathrm{cover}(q)\) |

**中文供形字（18，按「可能带着的知识」分组；每项都是完整字，不是部首切片）：**

| 该学的知识 | 完整字候选 |
|------------|------------|
| 封闭碗 / 字腔 | `口回日目田` |
| 横、交叉 | `一二十土` |
| 竖 | `川` |
| 斜 | `人八` |
| 弯、钩 | `乙了` |
| 竖 + 框 | `中申` |

例：参考是「十」时，`a` 的残差应对到 `口/日/o`，而不是整字更像 `a` 的 `n`。对应由 `cover` 算出来，上表只约束候选，不写死映射。

#### 4.5.3 推理规则（固定，评测前锁死）

对每个目标字 \(c\)：

1. 用 8 个中文 \(R\) 算 α，取 top-3 库字体，混同字 Δ。Δ **始终开**。  
2. 在 \(B_0\) 上算 \(\mathrm{gap}(c,R)\)。  
3. 若 \(\mathrm{gap}<\gamma\)：Support 为空（前向与阶段 A 相同）。  
4. 若 \(\mathrm{gap}\ge\gamma\)：按 `cover` + MMR 取 \(\mathrm{cover}\ge\theta\) 的 top-\(K\)，从 top-3 库取图，进 Support。

\(\theta,\gamma,\lambda\) 在 **训练字体里再划 4 套校准字体**（仍不是 Demo-8）上扫，锁写对最高的一组再测 Demo-8。提案 0.25 / 0.35 / 0.7 只是起点。

#### 4.5.4 训练时怎么采样（阶段 B）

与推理同一套规则：高 gap 喂支撑，低 gap 不喂。另加 **20% CFG**：整段丢掉 Support（不是丢掉 Identity），好做无分类器引导。不要再另做 50–70% 随机空支撑——空支撑已经由 \(\gamma\) 决定。

若校准后发现「几乎所有拉丁相对 8 个汉字都是高 gap」，则 \(\gamma\) 只起不到分流作用。那时把 \(\gamma\) 提到校准集上高 gap 三分位，而不是改主张。

#### 4.5.5 请拍板的点

1. 池用 **42 kNN** 还是先收成 **12 medoid**？（默认 42）  
2. \(M=3,K=3\) 是否接受？  
3. \(\tau_\alpha=0.07\)；支撑用残差 `cover` + MMR（\(\theta=0.25,\gamma=0.35,\lambda=0.7\)）是否接受为校准起点？  
4. 中文供形 18 字是否改名单？  
5. 标点：默认 **只走 Δ、不检索**。  
6. 残差先做 **全局向量投影**（默认，便宜）。若校准上看 `a` 仍捞不到圈，再把 \(E_c\) 改成空间图、按未覆盖 patch 检索（实现重一档）。

## 5. 和官方 FontDiffuser 差在哪

块留下，**条件怎么进网络**改掉。α 不是网络权重，是库字体混合系数。

### 5.1 官方一条样本怎么走

官方 Phase 1（中文→中文、同字）：

| 输入 | 进哪 | 干什么 |
|------|------|--------|
| 内容图 \(C\)：中性（或源字体）上的**同一个中文字** | content encoder \(E_c\) | 多尺度特征送进 **MCA**（下采样/中间块：拼到 hidden state 上做通道注意力） |
| 风格图 \(S\)：目标字体上的**同一个中文字** | style encoder \(E_s\) | 展平后做 **风格交叉注意力**（UNet 里 SpatialTransformer） |
| 同一张风格图 \(S\) | **再跑一遍** \(E_c(S)\) | 得到「风格图的结构特征」，送给 **RSI**：`OffsetRefStrucInter` 用它和 skip 做交叉注意力，预测 DCN 偏移，扭 skip |
| 噪声图 \(x_t\) | UNet | 预测噪声 |

要点：MCA 看内容字结构；RSI 看**风格字结构**。同文种、同字时两路结构能对齐，所以能扭。跨语时 \(S\) 是「十」、\(C\) 是 `a`，RSI 仍用「十」的骨架去扭 `a` 的 skip，这就是坏条件。

### 5.2 α 怎么用（不是训出来的一层权重）

α 在冻结的 \(E_s\) 上算完就固定（训练时当前字体 leave-one-out）。它只做两件事：

**① 混同字 Δ（始终开）**

\[
I_\Delta=\sum_{s\in\mathrm{top}M}\tilde\alpha_s\,I(B_s,c),\quad
\Delta=E_c(I_\Delta)-E_c(I(B_0,c))
\]

\(\tilde\alpha\) 是 top-\(M\) 重新归一化后的系数。物理含义：在「风格像用户参考」的那几套**训练库**里，把**同一个 \(c\)** 按 α 掺起来，再减去中性 \(c\)。得到的是「这个 `a` 该往哪变」，不是汉字轮廓。

**② 取完整支撑字时的库侧权重（gap 大才开）**

支撑图是库字体上的**整字** \(I(B_s,q)\)，\(q\) 由 `cover` 选出。库侧只用 α 的 top-\(M\) 套，样本权重 \(W^{\mathrm{sup}}_{q,s}=\tilde\alpha_s\cdot\mathrm{cover}(q)\)。α 不进 UNet 当通道注意力权重，也不去乘 MCA/RSI 里的卷积核。

风格本身仍只来自用户汉字 \(R\) 的 \(E_s(R)\)，和官方一样走风格交叉注意力。α 不替代 \(R\)。

### 5.3 MCA 改了什么

**块不拆：** 下采样 / mid 里的 `MCADownBlock`、`ChannelAttnBlock`（内容特征 concat + 可选 SE）保留。

| | 官方 | 我们 |
|--|------|------|
| MCA 的内容特征从哪来 | \(E_c(C)\)，\(C\) 与 \(S\) 同字同文种 | 仍是 \(E_c(C)\)，但 \(C\) 是中性字体上的目标字（拉丁 `a`） |
| 风格图进不进 MCA | 不直接进；风格走交叉注意力 | 同样不进 |
| 额外 | 无 | 可选把 Δ 加进内容特征（Identity + Change），让多尺度条件带「该怎么改」 |

改的是**送进 MCA 的张量语义**：只保证「还是 \(c\)」以及同字变化，**不再假设内容图和风格图结构同源**。论文里叫「多尺度身份条件」，架构图不写 MCA。

### 5.4 RSI 是什么、官方怎么实现、我们改哪

RSI（代码里 `StyleRSIUpBlock2D` + `OffsetRefStrucInter`）在 **UNet 上采样 skip** 上：用一张「结构图」去扭内容支路的 skip，再拼进解码器。它不是风格编码器，也不改噪声公式。

官方实现（同字中文）：

1. 风格图 \(S\) **再进一次** content encoder，得到多尺度结构特征 \(E_c(S)\)。  
2. 每个上采样块取出对应尺度：`style_content_feat = style_structure_features[-upblock_index-2]`。  
3. `OffsetRefStrucInter(skip, E_c(S))`：两边 1×1 投影后做交叉注意力（query=风格结构，context=内容 skip），FFN 后 `Conv2d → 2×3×3` 通道，当作 torchvision `DeformConv2d` 的偏移场。  
4. `skip_warped = DeformConv2d(skip, offset)`，再与上采样 hidden 拼接，后面仍是 ResNet + 风格交叉注意力。

物理上：把内容 skip 的空间格子，按风格字的骨架挪到该对齐的位置。同字时「永」对「永」格子能对上；跨语时用「十」的格子去挪 `a`，偏移场没有正确对应。

我们：**块和 DCN 都留**，只把第 1–3 步的结构源从 \(E_c(S)\) 换成 Δ 的空间特征。风格交叉注意力仍看 \(E_s(R)\)。

### 5.4b RSI 接线对照（官方 vs 我们）

**块不拆：** 上采样 `StyleRSIUpBlock` 里的 `OffsetRefStrucInter` + `DeformConv2d` 保留。

| | 官方 | 我们 |
|--|------|------|
| 算偏移的结构源 | \(E_c(S)\)，\(S\)=风格汉字（与生成字同字） | **禁止** \(E_c(R)\)。改为 Δ 的空间特征（同字、近邻风格相对中性的差） |
| skip 上 DCN | 用上面的偏移扭内容 skip | 同样扭 skip，但偏移来自 Δ |
| 风格交叉注意力 | 仍看 \(E_s(S)\) | 仍看 \(E_s(R)\)；完整支撑字以**另一类 token** 拼在后面，可长度为 0 |

官方：`offset = OffsetRefStrucInter(skip, E_c(风格汉字))`。  
我们：`offset = OffsetRefStrucInter(skip, Δ)`。  
Δ 接入层 / 偏移头按新输入形状初始化，阶段 A 训练。

论文里叫「变化引导对齐」，架构图不写 RSI。

### 5.5 一张图对照

```text
官方 FD:
  C ──Ec──► MCA（多尺度内容）
  S ──Es──► 风格交叉注意力
  S ──Ec──► RSI 偏移（用风格字结构扭 skip）   ← 跨语时这里病态
  x_t ──► UNet ──► ε

我们:
  C=中性c ──Ec──► MCA（身份；可加 Δ）
  R=用户汉字 ──Es──► 风格交叉注意力          ← 真风格只走这里
  库同字 × α ──► Δ ──► RSI 偏移              ← 形变源换成同字变化
  完整字 q × α ──► Support token（可空）
  x_t ──► UNet ──► ε
```

消融：官方接线（RSI 仍看汉字）vs 我们的接线（对齐看 Δ）vs 关掉 DCN、只靠交叉注意力。

## 6. 训练阶段

### 6.0 官方 FD，以及你已经做过的

官方是中文→中文、同字风格的两阶段去噪，不是 RL：

| 官方 | 数据 | 训什么 | 损失 |
|------|------|--------|------|
| **Phase 1** | 内容、风格、GT 都是同一中文字 | UNet + 两个 encoder | 噪声 MSE + CFG |
| **Phase 2** | 同上 | 加上冻结 SCR | 去噪 + 风格对比 |

仓库里和「Phase 1 上做跨语 SFT」相关的，已经有三条，**都不是现在的阶段 A**：

| 已有 | 实际是什么 | 和 A 的差别 |
|------|------------|-------------|
| 官方权重建模中→西 | **零微调推理** | 没训 |
| `ft_cnstyle`@42，25k | 官方 **原接线** 上，中文 style → 拉丁/假名 GT 的去噪微调；RSI 仍看汉字结构 | 任务已经是跨语，但形变源还是汉字；**没有 α/Δ** |
| 后来的 CN→CN FD★abs18000 | 中文扩写，另一条线 | 任务不是 CN→拉丁 |

所以：**跨语 SFT 做过；改接线 + Δ 的阶段 A 没做过。**  
`ft_cnstyle` 两件事：表里的「官方接线跨语微调」对照行；阶段 A 初始化时 **UNet 与两个 encoder 从 25k 接着用**，RSI 偏移头 / Δ 接入层按新输入重开。不要从官方 Phase 1 再冷启一遍跨语。

### 6.1 主线：A 然后 B

```text
ft_cnstyle @25k（官方接线、已跨语）
    → 改接线（对齐看 Δ，风格汉字不再进 content encoder）
    →【A】带 α/Δ 的跨语去噪微调     ← 推理默认
    →【B】冻 A，只训 SupportAdapter   ← 按 4.5.4 喂支撑
```

可选 R（扩散 DPO）放在 A 之后、B 之前。A/B 都是噪声 MSE，不是对话 SFT。

### 6.2 每一段

**A — 底座**

| | |
|--|--|
| 初始化 | `ft_cnstyle` 的 UNet + 两个 encoder；Δ 接入 / RSI 偏移头按新输入初始化 |
| 数据 | \(R\)=中文，\(C\)=中性拉丁，GT=该字体拉丁；库同字图算 α、Δ；无支撑 |
| 冻 | 两个 encoder。UNet 解冻 |
| 损失 | 噪声 MSE；随机丢 \(R\)、丢 Δ（20–30%） |
| 不训 | SCR、SupportAdapter、RL |
| 对照 | 无 Δ；官方接线（可用 `ft_cnstyle` 本身） |

**B — 支撑**

| | |
|--|--|
| 初始化 | 拷贝 A |
| 冻 | A 全冻 |
| 训 | 仅 SupportAdapter |
| 数据 | 同 A + 按 4.5 取出的 \(I(B_s,q)\)；20% CFG 丢 Support |
| 损失 | 噪声 MSE |

**R（可选）**  
对关支撑的 A 采整图。奖：写对/OCR、与 \(R\) 的 \(E_s\) cosine、与 \(C\) 内容一致、不要抄 α 最大库的同一字。不要 L1 对 GT，不要用官方 FD 当 reward 模型。
