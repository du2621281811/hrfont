## 0. 任务一句话

给一套**未见**中文字体几张汉字样张，生成同一风格的拉丁 / 假名 / 注音。官方 FontDiffuser 常把拉丁画成汉字笔画；我们用协议 A 数据微调，并对照「无 RSI / 官方 RSI / Δ-RSI / Δ+Support」。

## 1. 各臂实际改了什么（不要只看简称）

| 臂 | 网络里有没有 RSI | RSI 读到的结构条件 | Support×8 | 损失里的 offset 项 | 要回答的问题 |
|---|---|---|---|---|---|
| **官方 P1** | 有（预训练） | 参考汉字的 `Ec(style)` | 无 | 有（系数 0.5） | 基线：跨文字是否汉字化 |
| **E1** | 有（官方头，微调） | 同上 | 无 | 0.5 | 协议 A 上微调后能否写出目标字 |
| **F0** | **没有**：换 `StyleUpBlockNoRSI`，参数级删掉 offset 解释器 + DeformConv | 无 RSI 通道 | 无 | **系数 0**（且无模块可出 offset） | 去掉整段 RSI 后，拉丁是否还能写对 |
| **F1** | 有：在 F0 上**新挂** identity-safe RSI | 官方：`Ec(查询字体第一个汉字参考)` | 关 | 0.5 | 把官方 RSI 加回 F0，是否有用 |
| **F2** | 同上 | **Δ**：训练库 228 字体里用汉字 Es 找 Top-10，再取邻居**同一目标西文字**的残差加权 | 关 | 0.5 | 只换结构源为 Δ，相对 F1 |
| **F3** | 同上 | 同 F2 的 Δ | **开**：查询字体自己的 8 个汉字（不是检索结果） | 0.5 | 相对 F2，Support 是否再补风格 |

### F0 常见误解

- **不是**「只去掉 offset loss、网络里还留着 RSI」。
- **是** up-block 换成无 RSI 拓扑；从官方 P1 加载时丢掉 RSI/DCN 权重；`offset_coefficient=0.0` 是配套，不是唯一改动。
- F1/F2/F3 的 RSI 是挂在 F0 上的**新模块**，用 zero-conv 保证 step 0 ≡ F0 前向（identity-safe），不是从 P1 热启动官方 RSI 权重。

### Δ 检索（仅 F2/F3）

1. 查询字体 8 字（永和书风骨韵天地）的 Es，在 **train 228** 中 Top-10（`tau=0.07`，`k_top=10`）。
2. 取这 10 套字体上**同一个目标字符**的 Ec（相对中性字形）做加权平均 → RSI 结构条件。
3. 测试 16 套不在 228 里。训练时排除自身。`source_drop=0.25` 对 official / delta **同一套 RNG**。

### Support（仅 F3）

查询字体自己的 8 个汉字 glyph → `SupportAdapter` 拼进 up-path cross-attention；MCA down-path 的 style map 不变。`support_drop=0.2`。F2 也抽 support RNG 但不喂网络，保证 F2/F3 batch 对齐。
