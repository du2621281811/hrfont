3. 复制这段提示词给 GPT

请基于附件中的 FontDiffuser、CF-Font 方法图，画一张论文风格的方法总览图（类似 AAAI/CVPR 方法图：白底、模块方框、箭头、少数字公式）。

【任务】
未见过的中文字体 → 给若干汉字风格参考 → 生成同一风格的拉丁/数字/假名/注音。

【三种图必须分清渲染字体——画错就全错】
1) 内容参考图 Content：固定用 Noto Sans CJK Regular（中性字体）渲染「目标字符 c」。全数据共享，不随目标字体变化。图上必须画成无衬线/中性外观，并标注 “Noto / neutral”。
2) 风格参考图 Style/R：用「当前目标字体」渲染的汉字（不是 Noto）。训练随机 1–8 张；评测固定八字「永和书风骨韵天地」。图上要看得出是目标字体风格。
3) 近邻库图（仅用于构造 Δ）：训练库 228 套字体上、与 Content 同一个字符 c 的字形；测试字体不进库。
减数 G(Content,c) 与内容参考是同一张 Noto 图，不要另画第二套中性字体。
真值 GT 是目标字体上的字符 c，只作对照，不是条件输入。

【FontDiffuser 骨架（灰色细线框，整体标注 Inherited denoiser backbone）】
- Content（Noto, 字符 c）→ Ec/MCA → diffusion UNet
- 基础 Es 与 UNet style-conditioning 接口
- diffusion objective / sampler
- 不把 RSI 作为本文贡献高亮；若底层复用 DCN，仅标注 inherited operator

【本文方法一：Set-Delta Variation Prior（蓝色粗线框）】
1) 用目标字体 ref8 在 train-bank 检索 Top-K 相似字体；Alpha 只作 proposal 与 logit bias；
2) 对每个 donor，取与 Content 同一目标字符 c 的规范化边界表示；
3) 分别减去固定 Noto 中性锚点，得到 K 个 donor residual candidates；
4) 保留候选轴，不在网络外加权平均；
5) Target-Character Variation Adapter 在目标空间位置聚合候选，通过 warp/value geometry paths 进入 UNet。

【本文方法二：Graphics-Informed Local Reference Attention（橙色粗线框）】
1) 每张 ref 保留独立 global token；
2) 从 Es 中层特征取得 learned local style values；
3) ink/radius/orientation/endpoint/junction 图形描述符构成跨字符匹配 Key；
4) Content 局部结构作 Query，读取目标字体 ref 中相符的 appearance evidence。

【不要画入主方法】
- own-font Support：只作额外观测工程模式或 oracle upper bound；
- “Delta-RSI，只换官方 RSI source”的旧图；
- 把 Alpha 画成唯一答案或把 K 个 donor 预先平均。

【图面要求】
- 左或外围：FontDiffuser denoiser backbone（灰色、整体标注 inherited）
- 中间：Set-Delta 候选轴与 Target-Character Variation Adapter（蓝色高亮）
- 另一支：Graphics-Informed Local Reference Attention（橙色高亮）
- 内容分支与风格分支在图上分列，并在 Content / Style 框内写明渲染字体
- 旁注：训练时风格参考随机 1–8 张；评测固定八字「永和书风骨韵天地」
- 不要画实验消融表、不要堆内部代号（F0/F1/F2…）；模块用中英文全称
- 输出横向论文图，分辨率适合单栏或双栏插图

6. 必须出现的公式

JK(R) = TopK(sim(Es(R), Es(bank)))，Alpha 只作 proposal / logit bias

dj,c = G(bankj,c) − G(Notoc)，j∈JK(R)

Dc(R) = {(dj,c, log αj)}；保留 candidate axis 到空间聚合

output = Gθ(xt, Contentc, Dc(R), RefEvidence(R))

要点：Delta 提供 bank-supported variation；Ref 提供目标字体中实际可观察的 appearance evidence；不把 donor 预平均成唯一答案。

7. 和两篇基线的一句话差别

  • vs FontDiffuser：FD 做 reference imitation；HR-Font 显式建模未观察目标字符的 retrieved variation prior，并与 observed reference evidence 分路。
  • vs CF-Font：都利用 bank 字体；HR-Font 保留同目标字符相对固定锚点的 donor candidate axis，直到目标空间位置聚合，而不是先形成单一融合内容。

8. 不要画进主方法图的东西

  • 把 Content 画成目标字体样式，或把 Style 画成 Noto——这是最常见错误。
  • 实验消融编号表（无结构迁移 / 官方 RSI / 近邻残差 / 支持特征对照）→ 那是实验图，不是方法图。
  • 像素指标、训练曲线、GPU、checkpoint 步数。
  • Support / own-font extra images：不进入论文主方法图，只能在工程模式或 oracle upper bound 图中单独披露。
  • 把测试字体画进训练库；库是 train228，测试字体只作查询。

9. 建议版式

  • 方案 A（推荐）：单张横向总览；左侧 Inherited 骨架，右侧高亮 Δ 分支。
  • 方案 B：上排 FontDiffuser 官方结构条件（小、灰），下排 Ours（大、彩）。
  • 颜色不超过 3 种强调色；模块名中英均可，公式用 Δ、Ec、Es。
