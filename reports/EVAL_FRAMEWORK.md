# HR-Font 跨语系字体风格迁移：自动化评测框架设计（v1）

> 状态：设计稿，待确认后实现。对应报告 `ICLR2027_HRFONT.md` 第 7 节的评测环节。
> 原则一句话：**GT 是校准，不是目标。** 跨语系任务不能追求与 GT 像素级相似，评测应围绕「生成的西文字形是否合理地属于参考中文字体家族」展开，后续用设计师问卷验证本框架。

---

## 0. 为什么 GT 像素相似度不能当单一标签

1. **GT 只是风格分布的一个样本**：同一字族内同一字符存在多个合法设计（如单层/双层 `a`、不同衬线处理），像素指标惩罚所有合法变体、奖励向 GT 的 mode collapse。
2. **few-shot 参考本身欠定**：8 个汉字不足以唯一确定一个字体家族，合法输出空间大，L1/LPIPS 衡量的是「离某一个 GT 有多近」而不是「是否属于这个风格」。
3. **跨语系无像素对应**：中文参考与西文目标拓扑不同源，不存在「正确像素级对齐」，官方 RSI 用汉字骨架扭拉丁正是这个病态的体现——用像素指标做目标等于变相要求模型复现这个病态。
4. 现有同语系字体生成工作（LF-Font AAAI'21、MX-Font ICCV'21、CF-Font CVPR'23、FontDiffuser AAAI'24 等）普遍依赖 L1/LPIPS/SSIM/FID + 小规模用户研究；它们的用户研究恰恰说明自动风格指标缺位。我们补的正是这块。

**评测应该回答三个正交问题**：
- 这是不是目标字符 c？（身份正确性）
- 它像不像参考字体的风格？（风格一致性——核心）
- 它是不是一张干净、可用的字形？（生成质量）

## 1. 三条设计原则

| 原则 | 内容 | 防止的问题 |
|------|------|-----------|
| P1 | **GT 是校准不是目标**：所有指标同时报 GT 自身得分作为天花板，模型结果以「离 GT 天花板的差距」呈现 | 指标系统性低估/高估、OCR 难度差异 |
| P2 | **评测编码器与方案编码器隔离**：方案的 α 用官方冻结 Es 估计，评测风格指标**不得用同一个 Es**（循环论证：方法按 Es 余弦选库字体，再用 Es 打分等于自己出题自己判）。评测用独立训练的跨语系风格编码器 φ_s2（见 §3），Es 只作为对照 | 循环论证 |
| P3 | **阈值冻结**：任何阈值（gap 分层、pass 线、OCR 置信度）只在**校准字体**上确定，测试时不得用待评输出重新标定。历史 `style_metrics.py` 的 `srr_pass_rate` 自指阈值错误（Codex M9）不得再现 | 自指指标（按构造恒为 ~75%） |

## 2. 指标轴定义

符号约定：参考集 `R = {r₁…r₈}`（`永和书风骨韵天地`，目标字体 f★ 上的渲染）；生成字形 `g`（目标字符 c）；`GT_c` = f★ 真实西文渲染（评测时可用，仅作校准）；库字体池 `P`（42 训练字体，Demo-8 永不进入）；中性底 `B₀`（FZKTJW）。

### 2.1 身份正确性 Identity（写对）

目标：g 是字符 c，不是别的字。

- **ID-OCR**：单字 OCR 识别准确率（引擎：TrOCR-small 本地跑，或 DashScope qwen3.8-flash 兜底）。同时报 `ID-OCR(GT)` 作为引擎难度校准，正式表用 `ID-OCR(g)/ID-OCR(GT)` 归一化（相对准确率）。
- **ID-NN**：最近类分类。`argmax_c' cos(Ec(g), Ec(B₀[c']))`，Ec = 冻结官方 content encoder。返回 top-1 准确率 + **混淆矩阵**。
- **诊断价值**：混淆矩阵按 gap 分层输出——预测「封闭字腔类字符（a/d/o/p/q）互相混淆」正是拓扑缺口假设的直接证据，进论文附录。

### 2.2 风格一致性 Style（核心轴）

用风格编码器 φ 把 g 与参考原型比较：

```
μ_R = normalize( (1/8) Σᵢ φ(rᵢ) )
SC-R(g)   = cos(φ(g), μ_R)                    # 生成字形对参考的风格一致性
SC-GT     = cos(φ(GT_c), μ_R)                 # GT 天花板
SC-Gap    = SC-GT − SC-R(g)                   # 主报告量：离天花板多近
```

- 主表报 `SC-R`、`SC-GT`、`SC-Gap` 三列。**不报 GT 对 GT 的同类对比**（即旧 FIC 的 cos(φ(g), φ(GT_c))），因为那又回到追 GT。
- **φ 的选择（关键）**：
  - φ_s1 = 冻结官方 Es（FontDiffuser P1 style encoder）：零成本，跨语系泛化能力未知，仅作对照；
  - **φ_s2 = 跨语系对比学习风格编码器（见 §3）**：评测主编码器。
- **Rank@1 判别式变体**（更强证据）：用 42 套库字体各自的 ref8 建原型 `μ_s`，连同目标原型 `μ_R` 共 43 个原型；查询 `g`，报告目标原型是否 top-1（Recall@1）。同时报 GT 的 Recall@1 作天花板。这个指标直接回答「生成的 g 是否被识别为属于参考字族」。

### 2.3 生成质量 Quality

- **Q-Cov**：墨迹覆盖率 ∈ [0.5%, 60%]，空白率/溢出率单独统计（拒绝空图与糊成一团）。
- **Q-LPIPS**：`median_c LPIPS(g, 最近库字体的同字渲染)`——离「任何真实字体渲染」的距离，作为伪影检测器（雾、断笔、纹理噪声都会拉高它）。它不是风格目标，只是质量下限。
- 可选（成本可控时）：VLM 1–5 分可读性，只跑子集，用于问卷前自查。

### 2.4 gap 分层（论文主图支撑）

- `gap(c,R) = ‖v_c^miss‖₂ / ‖v_c‖₂`（`v_c^miss` 为 v_c 在参考整字特征子空间投影后的残差，见 `ICLR2027_HRFONT.md` §4.3）。测试时**不需要 GT**，可对任意 c 预计算。
- 分层边界（低/中/高三分位）在**校准字体**上冻结，测试集直接用。
- 所有指标（ID / SC-Gap / Q）按层输出；主图：**Δ(Stage B − Stage A) 随 gap 增大而增大**。

## 3. 跨语系风格编码器 φ_s2

动机：Es 只在中文上训过，跨语系风格表征能力存疑；且与方案共享（P2 循环）。φ_s2 必须独立训练、独立验证。

- **数据**：**项目字体池之外的公开字体**（Noto Sans CJK 多字重、Source Han Sans/Serif、Google Fonts 免费中文字体等，均自带西文字形）。同族 (中文 glyph, 西文 glyph) 为正样本对，异族为负。完全不碰 42 训练字体和 Demo-8 → 零泄漏。
- **结构**：ResNet18 + GAP + L2 归一（或 ViT-S），小模型，M5 本地 MPS 或集群闲置卡数小时可训完。
- **损失**：InfoNCE，τ=0.07；轻增强（±3° 旋转、±5% 缩放、对比度抖动）保证对渲染噪声稳健。
- **验证（训练后、用前必过）**：在**未见字体族**上跑 T2（§4）。

## 4. 指标自测（信任前必过）

全部在**校准/外部字体**上完成，Demo-8 不参与任何指标开发：

| 编号 | 测试 | 判据（起点值） | 失败含义 |
|------|------|--------------|---------|
| T1 | GT 自一致性：cos(φ(GT_c), μ_R) 在 held-out 字族上 | φ_s2 ≥ 0.6（φ_s1 仅记录） | 编码器无法桥接语系，SC-R 无意义 |
| T2 | 分离 AUC：同族 vs 异族 (g, R) 对的 SC-R 分类 AUC | ≥ 0.90 | 指标没在测风格 |
| T3 | 身份校准：GT 渲染的 OCR 准确率 | ≥ 0.85（否则改用 ID-NN 为主） | 引擎对风格化字形太弱 |
| T4 | 参考敏感性：把 R 换成错误字族 refs 后 SC-R 应单调下降 | 下降显著 | 指标对风格不敏感 |

T2 是本框架的**核心验证**：它不依赖人评、全自动，且能在问卷前就证明「SC-R 测量的是风格而非内容残留」。

## 6. 设计师问卷验证协议（第二阶段）

目的：证明自动化方案与设计师判断一致（指标选择 + 校准 + 论文人评证据三合一）。

**题本设计**：
- **2AFC 风格题**：「以下两个字形，哪个更像参考字体？」对每对方法（FT vs Stage A、Stage A vs Stage B、零样本官方 vs 完整方案）在 {低 gap, 高 gap} 两层各抽 ~15 字符 × 若干字体，锚定 ref8 并排展示。
- **绝对 MOS 题**：单图风格契合度 1–5（用于校准 SC-R 的绝对阈值）。
- **身份题**：给出 g，问「这是字符 c 吗？」（验证 ID 轴与人的一致性）。

**一致性分析**（问卷的产出不是「设计师更喜欢谁」，而是「自动化指标能否预测设计师」）：
1. 设计师间一致性：Fleiss κ（先证明人评本身可靠，κ < 0.4 则题本/展示有问题，先修问卷再收数据）。
2. 指标-人评相关性：每对方法的 SC-Gap 差值与设计师 win rate 的 Kendall τ / Spearman ρ。
3. 预测能力：SC-Gap 差值作为特征预测 2AFC 结果的 AUC。
4. 分层一致性：低/高 gap 两层分别重复上述分析。
5. 校准：在独立校准子集上确定「SC-Gap 低于何值 = 与 GT 无显著差异」的 pass 线，测试集直接套用（P3）。

**验收标准（建议）**：τ ≥ 0.7 且 AUC ≥ 0.8 → 方案成立，自动化指标可放大到全 Demo-8 并在主表使用；不达标 → 换 φ / 改题本，不硬发。

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| φ_s2 训练不收敛 / T2 AUC 不达标 | 先用 φ_s1 + 冻结 T1–T4 全过再决定；T2 不过就换骨干（ViT-S）、扩外部字体池，仍不过则回到「Es 对照 + 弱化自动化主张」并加大问卷样本 |
| 单字 OCR 对风格化字形整体偏弱（T3 不过） | 主指标切 ID-NN；OCR 只做相对校准 |
| SC-Gap 与设计师判断相关性不足（τ < 0.7） | 问卷阶段本来就是指标选择的验证器：φ_s2 vs φ_s1 vs Rank@1 三选一；不硬发 |
| 问卷收集成本 | 分层抽样控制题量（每层 ~15 字符 × 4 方法对 ≈ 120 题/人，3–5 位设计师）；低 gap 层可以减半 |
