# G0 超参设计（审查稿）

> Group **G** = `v0913_clean` 上的 8 卡快验。不覆盖已有 F0 / F0-c / F0-c-128 目录。  
> 前提：**8 卡全开，要尽快出第一张可读图。** 在跑任务可中断。  
> 状态：**G0b 开训。** 2026-09-13。旧 G0 已停、目录保留。流水线：G0b → cache → **G2** → G1 ∥ **G2-RL**。

## 1. 128 还是 256

**选 256（8×32，accum=1）。**

8 卡上 256 是自然切分：每卡 32 已在本机测过（约 23GB，无 OOM）。  
8×16=128 每步更快，但样本吞吐更低；要对齐 256@5000 的数据量必须走到 **10000 步**，墙钟还更慢。

| | 8×16 = 128 | 8×32 = 256 |
|---|---|---|
| 步时（估） | 0.55–0.65 s | **0.80–0.90 s**（4×32 实测 0.79） |
| 样本/秒 | ~200–230 | **~290–320** |
| 更新/秒 | 更高 | 略低 |
| 线性 lr | 1.6e-4（F0-c-128 已能降） | 3.2e-4（未测，warmup 500 兜） |
| 第一可读点 | 要 10k 才对齐数据量 | **5k 就有 23 epoch** |

要快：256@5000 约 **1.2 h** 出主点。128 要 10k 才够，约 **1.6–1.8 h**，更慢。

## 2. 若仍用 128，走多少步

不要用 5000。5000@128 只有 64 万 pair（11 epoch）、5000 次更新，比 256@5000 瘦一倍数据。

| 对齐目标 | 128 步数 | epoch | 更新 |
|---|---|---|---|
| 对齐原 F0-c **样本**（32 万） | 2500 | 5.7 | 太少，不要当终点 |
| 对齐 256@5000 **样本**（128 万） | **10000** | 22.7 | 10000 |
| 对齐 256@10000 **样本**（256 万） | 20000 | 45.4 | 20000 |
| 对齐原 F0-c **更新**（4 万） | 40000 | 90 | 慢，不是快验 |

128 的快验日程：**max_steps=10000，主看 10000**（5000 只作中点，不当结论）。

## 8. G0b：lr=1e-5 时的 AdamW / warmup / scheduler

batch **仍 8×32=256**。lr 改回与单卡 F0 相同的 **1e-5**（不线性、不 √ 放大）。死亡线约 1.2e-4，1e-5 在安全区。

AdamW **不要改**，继续用 F0 / F0-c 已跑稳的默认：

| 项 | 值 | 为什么保持 |
|---|---|---|
| β1 / β2 | **0.9 / 0.999** | 标准 AdamW；大 batch 每步样本更多，二阶矩更稳，不必改 β2 |
| weight_decay | **0.01** | 与 lr 解耦；lr 没放大，wd 也不要动 |
| eps | **1e-8** | F0-c 单卡 1e-5+fp16 用这个跑到 16.5k 无 NaN |
| max_grad_norm | **1.0** | 已有 clip；不是这次爆炸的原因 |
| `scale_lr` | **关** | 绝对值已定为 1e-5 |

不要：把 eps 改成 1e-6、把 β2 改成 0.99、按 batch 放大 wd。那会和「只改 lr」混在一起，下次炸了说不清。

日程：**`constant_with_warmup`，warmup 500。**

| 步 | lr |
|---|---|
| 0 → 500 | 0 → 1e-5（线性爬） |
| 500 → 10000 | **保持 1e-5** |
| 5k / 10k 读点 | 都是 1e-5 |

warmup 取 500 的理由：

- F0-c 是 5000@bs=8，按样本折到 256 只要 `5000×8/256≈156` 步。500 已经盖过。
- Adam 还要几百次更新才把 v 估稳，500 次更新够；1e-5 峰值小，不必 1500。
- 10k 短程里 warmup 再长，5k 主点前面有效更新更少。

不要用 `linear → 0 @10k`：5k 时 lr 会掉到约 5e-6，等于没在设计值上读数。`cosine` 同理。纯 `constant`（无 warmup）省事但前几步 Adam 分母很小，留 500 步更稳。
